# Object-literal site screen

Host: Apple M4, macOS 26.5, arm64. Production candidate binary SHA-256: `697a169197b8a6218cfba410bb3fd16a72f3948b846d53c0c3a7d31193be3c02`; baseline: `2854be3031531d0e71cbdd4098ae8bdfb64079aff34831a6e9c28bce4113f7b7`. The candidate uses the repository's production-thin-LTO profile, codegen-units 1, panic abort.

The static 3+ data-property literal path reduced median per-operation cycles by 82.56% over 11 alternating pairs (95% bootstrap interval 81.91%–83.25%), and retired instructions by 77.22%. Median maximum RSS rose 65,536 bytes (0.364%), inside the named 0.5% change budget. The same screen showed no 2-key or nested-array 2-key benefit: their cycle intervals include zero and instructions were slightly higher. Full pairs and analysis are in [gate-summary.json](task61-object-literal-screen-2026-10-09/gate-summary.json) and [gate.json](task61-object-literal-screen-2026-10-09/gate.json).

The per-op reference screen puts the existing 2-key path at 712 median cycles against Node `--jitless` at 39.9 (17.85x); a nested-array 2-key literal is 1,203 against 104.1 (11.55x). This establishes the next local target, but not a fixture gain. The per-op measurements are in [per-op-references.json](task61-object-literal-screen-2026-10-09/per-op-references.json).

The profile-aggregate site census separates setup from one benchmark run. Splay executes 504,000 two-key constructions in setup and 5,040 in one run; its hot sites remain `MakeObject2` and `SuperConstArrayObject2`. RayTrace executes the 3+ key path twice in one run. EarleyBoyer's sole 43-key site executes once during setup and not in the measured run. The census is [site-census.json](task61-object-literal-screen-2026-10-09/site-census.json), generated by [task61-object-literal-census-2026-10-09.py](task61-object-literal-census-2026-10-09.py).

The 11-pair RayTrace fixture gate did not establish a time benefit: median paired cycle improvement was 0.665%, its 95% interval was -8.02% to +3.38%, and the candidate won 6/11 pairs. Median maximum RSS was 1.49% lower. Treat the fixture result as inconclusive; the retained claim is limited to the isolated 3+ literal path. Raw runs and the materialized input are in [raytrace-fixture-gate.json](task61-object-literal-screen-2026-10-09/raytrace-fixture-gate.json).

Correctness: the object-literal test checks left-to-right value evaluation, key order, values, descriptors, register roots, and specialized/unspecialized execution. It passed with `profile-aggregate`; the rewrite-recipe schema test also passed. The preceding candidate passed Test262 Stage 60 (3,411/3,411) and matched the Node oracle. The profile counters are feature-gated and excluded from production builds.
