# Splay GC share of marginal wall time (M4)

This diagnostic pairs the exact V8-v7 Splay fixed-work input at 300 `run()` calls with its setup-only `K=0` twin. The `profile-gc-time` build times only the collector's mark, sweep, and mark-clear phases; it does not enable per-opcode aggregation. Each measured series first runs an excluded K=0/K=300 warm-up pair to prime process and input pages. It alternates setup/work order and accepts only pairs with clean load, successful markers, positive marginal wall time, nonnegative marginal GC phase time, and at least as many collections in K=300 as K=0. Schema 2 records valid-pair count and rejected attempts.

The feature adds three `Instant` timers around GC phases and a small three-counter record to diagnostic builds only. It does not change production builds. The runner refuses a sample when one-minute load exceeds 1.0 per logical CPU and records pre/post load for every process. Its default is the pinned diagnostic binary named by SHA-256 in `measure.py`; set `QUENCH_GC_PROFILE_BINARY` to override it. A complete 11-pair report is written to `gc-share-11.json`; incomplete attempts go to a separate file so they cannot replace a completed result.

`gc-share-first-pass-cold-start.json` preserves the initial schema-1 attempt. Its first pair had a cold-start anomaly (K=0 wall exceeded K=300 despite lower CPU use), so it is not used for the derived share. The warmed schema-2 retake is `gc-share-11.json`: 11/11 valid pairs on M4 arm64 macOS, source `ab6e3f8c6`, pinned binary SHA-256 `a486ee1e7698546fc5d8427dd7e48a5904e676ebe9bfab6d643c5e36e67dc746`. Median K=300 minus K=0 marginal wall was 440 ms (range 390–480 ms); mark was 43.62 ms (9.92%), sweep 16.09 ms (3.66%), and mark-clear 0.0025 ms. Combined mark+sweep was 13.74% of marginal wall (per-pair range 12.93–16.82%); mark was 73.1% of mark+sweep. The runner observed load below 0.563 per logical CPU in every sample. This bounds ideal parallel-GC speedup to less than 13.74% before coordination costs; the main relevance is enabling lower headroom for the RSS target.
