# TOD-20 HTTP outgoing callback regression fix v303

This follow-up tightens the v300 HTTP response backpressure change. Writable's own buffered length already includes deferred callbacks, so `ServerResponse.writableLength` now adds only the HTTP chunk-framing bytes and no longer counts the same payload twice. End-body writes invoke their write callback immediately while normal `response.write()` callbacks remain queued until host flush; this restores Node's repeated-`end()` callback and `finish` ordering.
