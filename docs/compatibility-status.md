# Compatibility status

This is the current evidence-backed compatibility boundary for quench-node.
It is intentionally narrower than the broad Node 24 release contract in
`docs/compatibility-contract.md`.

## Proven locally

- 2,415/2,415 focused compatibility stages pass in the serial authoritative
  runner, with zero failures and zero retries.
- The six maintained application gates pass: Ajv, debug, Chalk, ms, Prettier,
  and `process.argv0`.
- The maintained examples pass: CLI summary, crypto file summary, HTTP
  loopback, and stream summary.
- Built-in module inventory reports 58/58 canonical modules registered.

The focused evidence is generated by:

```sh
tools/check-focused-stages.sh
tools/check-application-stages.sh
tools/run-examples.sh
```

## Not proven

This evidence does not constitute broad Node 24 compatibility. The current
goal audit still reports unfinished task records, global-surface gaps, and no
fresh complete differential corpus report. Native addons and Node-API remain
outside the contract, while native TLS/HTTPS/HTTP2, inspector, QUIC, and other
host-integrated boundaries retain their documented platform classifications.

Before declaring the broad release contract complete, refresh the full
differential report, resolve or classify its non-matches, complete the task
index, and obtain the required second clean verification run.
