# Deegen reference

[Deegen](https://arxiv.org/abs/2411.11469) is design background, not Quench's
acceptance specification. The active contract is
[stencil JIT implementation](stencil-jit-implementation-spec.md).

Do not infer implementation from shared terminology: an eligibility fact is not
type-check elimination, a placement model is not emitted IC code, a Rust bridge
is not a composed native region, and a tier name is not an optimizing compiler.

Verify each claim through current code and executed tests. Old paper-alignment
tables and counts are preserved in Git history. Legacy instrumentation proxies
are described in [the curriculum manual](deegen-micro-curriculum.md).
