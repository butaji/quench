# Architecture & Code Review — 2026-08

Scope: ~95k LOC (199 Rust files, 34 JS builtin files), the test262 runner,
`tasks/index.json`, and tooling. Bugs marked **verified** were reproduced
against the built CLI (`./quench`). No files were changed by the review.

Judged against the project goal: **100% test262 conformance with the
minimum possible Rust LOC.**

## P0 — architecture premise vs reality

1. **The self-hosted JS builtins layer is dead code.** `bootstrap_js_builtins`
   (`builtins/bootstrap.rs`) is never called by `Context::new()`,
   `init_builtins` (`context/helpers.rs:236` explicitly skips it), the CLI, or
   the test262 runner — only by unit tests. The comment there documents why:
   the JS wrapper pattern caused infinite recursion. Conformance today is
   achieved entirely by the Rust builtins. The dormant layer (1,570 LOC,
   including `Array.js` = 570 LOC re-implementing `builtins/array/methods/*`)
   also carries spec bugs that would fail test262 if enabled: `keys()`/
   `values()`/`entries()` return plain arrays instead of iterators,
   `splice`/`with` mishandle negative indexes, `includes` uses the wrong
   SameValueZero. This is decision **R22**: revive-and-migrate or delete.

2. **Verified conformance bugs on the live Map/Set path.**
   - `same_value_zero` (`value/compare.rs:70`) falls through to `a == b` for
     Symbols, and `Value::PartialEq` returns `false` for all Symbols
     (`value/val.rs:795`). Verified: `m.set(s, "v"); m.get(s)` → `undefined`;
     `new Set([s]).has(s)` → `false`. **R18.**
   - Map internal slots leak as own enumerable properties: `Object.keys(new
     Map())` → `_entries,size` (spec: `[]`); slots are stored via plain
     `.set()` in `map/helpers.rs::init_map_object`. **R19.**

3. **`__ops__` bridge violates the one-canonical-path rule** (`eval/ops.rs`):
   `IsCallable` misses callable objects; `HasProperty` implements `has_own`;
   `SameValueZero` calls `same_value` (so `-0` vs `+0` is wrong);
   `CreateDataProperty` uses `.set()`; `DefineProp`/`SealObject`/`FreezeObject`/
   `SetPrototypeOf` inline-reimplement descriptor logic — a second
   defineProperty path alongside `builtins/object_static/descriptors.rs`.
   Only consumer today is the dormant JS layer. **R21.**

4. **Loose equality bypasses the canonical `ToPrimitive`**
   (`value/compare.rs:209-296`, live via `eval/operators.rs:19`):
   hand-rolled valueOf/toString walk ignores `Symbol.toPrimitive`, swallows
   throws, and `parse_number_string` overflows `u64` on long hex strings.
   **R20.**

## P1 — process & integrity

5. **Stage ledger contradicts the gate.** `tasks/index.json` marks stages 27
   (generators), 32 (switch), 34 (try) `done` with recorded pass rates below
   100% (see the file). README: "If a stage is not 100% in the test runner
   output, it is not done." Progress data is only ever updated through the
   runner workflow — re-run those stages and reconcile. **R24.**

6. **Linter gates don't hold.** `cargo clippy -p quench-runtime --all-targets`
   prints 16 lib + 2 test warnings and exits 0 (incompatible_msrv, identical
   `if` blocks, `Arc` not Send/Sync, complex types). 77 `#[allow(...)]` in
   `src/` (AGENTS.md forbids them). Files far over the stated 500-line cap:
   `eval/class/helpers.rs` (3863), `early_errors.rs` (3264),
   `eval/statement.rs` (2053), `builtins/typed_array.rs` (2255),
   `object_static/descriptors.rs` (1468), `builtins/bootstrap.rs` (1479).
   Note: `.clippy.toml`'s `too-many-lines-threshold` is a **per-function**
   lint — there is no clippy enforcement of a per-file cap. **R27.**

7. **Ambient state: 48 `thread_local!` slots** (interpreter.rs alone has 17),
   against the "shrink toward zero" principle: strict mode as a global
   `Cell<bool>` saved/restored at eval boundaries (`interpreter.rs:290`),
   generator suspend state staged in thread-locals (`eval/iteration.rs:161`,
   `eval/generator.rs:46`, `value/generator_replay.rs`), an accumulator stack
   (`eval/statement.rs:20`), and `CURRENT_SOURCE` via
   `transmute::<&str, &str>` with no RAII cleanup (`context/mod.rs:89`).
   **R23.**

8. **Dead code and dependencies.** `anyhow`, `tracing`, `phf` declared in
   `Cargo.toml` with zero uses in `src/`. `interner.rs` (`StringInterner`) is
   constructed/reset in every `Context` with zero readers — and
   `docs/architecture.md` says string interning is deferred. `#[allow(dead_code)]`
   markers on `ClassValue::from_ast` (`value/val.rs:239`),
   `to_primitive_for_compare` (`value/compare.rs:208`), `Context::env`
   (`context/mod.rs:241`). **R25.**

9. **Missing files referenced by AGENTS.md.** `tasks/refactor-plan.md` and
   `tasks/plan.md` are referenced but did not exist; `tasks/` contained only
   `index.json` and `meta-analysis-stream.md`. (Fixed by this update; see
   `tasks/refactor-plan.md`.)

## P2 — LOC & cleanliness

10. `Context::eval` / `eval_es_module` / `eval_typescript` are three
    near-identical ~40-line copies (`context/mod.rs:77-200`). **R26.**
11. `register_native` hardcodes global `length` values in a match
    (`context/mod.rs:253`). **R28.**
12. Where JS files exist (Map.js, Set.js, GeneratorPrototype.js) they are thin
    receiver-check shims over native impls — the "self-hosted" story is a
    facade even there. (Part of R22.)
13. `builtins/bootstrap.rs` carries contradictory phase numbering, commented-out
    entries, and "removed … causes infinite recursion" comments — a file that
    documents its own abandonment. (Part of R22.)

## What's good

- Skip policy is principled: zero skips, zero crash-file carve-outs; crashes
  become failures via process isolation (`run-test`, `RUST_MIN_STACK`).
- One canonical property store (`value/object.rs`); `strict_eq`/`same_value`
  handle NaN and ±0 correctly.
- TDD discipline is real: focused unit tests sit next to code; stage runs are
  the conformance gate.
- Digest/metadata tooling (`TEST262_DIGEST`, `tools/*.sh`) is coherent and
  consistent with the runner.

```bash
cargo test -p quench-runtime --lib             # 3077 passed / 7 failed (generator area, mid-refactor)
```
