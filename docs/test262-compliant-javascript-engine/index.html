How Quench reports conformance, and what the 53 waivers are.

Quench passes 53,353 Test262 tests with 0 failing, with the JIT off and on. 53 cases are waived because they fail exactly the way Node.js fails them; they are listed with reasons and still counted as failures in every report. The WebAssembly spec suite passes 67,124 of 67,124.

How conformance is enforced

The Test262 runner in crates/quench-test262 reports every raw outcome. Test262 runs in interpreter and JIT modes before changes merge. A waiver must name a case that Node fails in the same way; it is rejected the moment the case starts passing or fails differently. The list: node-waivers.json. History: Test262 and the skip list.

Questions

Which JavaScript engine passes Test262?

Quench, a JavaScript runtime written in Rust, passes 53,353 Test262 tests with 0 failing and 53 waived, with the JIT off and on. The 53 waived cases fail exactly the way Node fails them and stay counted as failures in every report.

What are the 53 waived Test262 tests?

Cases where Node.js itself fails in the same way, for example Node has no Error.prototype.stack accessor. Each is listed with a reason in node-waivers.json, and a waiver is rejected as soon as its case starts passing or fails differently.

Does Quench pass the WebAssembly spec tests?

Yes: 67,124 of 67,124 WebAssembly spec suite cases.

About Quench

Quench is a JavaScript, TypeScript and WebAssembly runtime written in Rust. Test262: 53,353 passing, 0 failing. Interpreter, two JITs, and AOT to native executables. It is MIT licensed, early, and built from source with Cargo. Source: github.com/butaji/quench. Machine-readable summary: llms.txt.
