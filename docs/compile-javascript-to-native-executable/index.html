Compile JavaScript to a native executable

Quench's AOT compiler turns a JavaScript or TypeScript program into machine code, not a bundled script.

Quench compiles a JavaScript or TypeScript entry file and its imports ahead of time into one native executable: quench --build-aot app.ts -o app. The program is lowered to machine code with the same meaning as Quench's interpreter; the full interpreter and JITs are left out unless the program uses eval or new Function. AOT is experimental and no AOT speed numbers are published yet.

Usage

cargo build --release -p quench --features aot
./target/release/quench --build-aot app.ts -o app
./app

One semantics

Each opcode's meaning is written once. The interpreter runs it directly, the JITs and the AOT compiler emit it as machine code. That is the interpreter specialized to what is known about the program (a Futamura projection), so an AOT-compiled program and an interpreted one agree. Background: AOT without a second compiler.

Limits today

  • Built and tested on Linux, from a source build with --features aot.
  • No published speed numbers; the target is within 5x of equivalent C on every JetStream benchmark.
  • Node API compatibility is still being built out.

Questions

How do I compile JavaScript or TypeScript to a native executable?

With Quench built with the aot feature, run quench --build-aot app.ts -o app, then ./app. The entry file and the modules it imports are compiled ahead of time into one native executable.

Is the Quench AOT compiler faster than Node?

No AOT speed numbers are published yet. The goal is AOT code within 5x of the equivalent C program, and it is not yet met on every benchmark.

Does an AOT-compiled Quench program include an interpreter?

The full interpreter and the JIT tiers are left out of the executable unless the program uses eval or new Function, which need to compile code at run time.

About Quench

Quench is a JavaScript, TypeScript and WebAssembly runtime written in Rust. Test262: 53,353 passing, 0 failing. Interpreter, two JITs, and AOT to native executables. It is MIT licensed, early, and built from source with Cargo. Source: github.com/butaji/quench. Machine-readable summary: llms.txt.
