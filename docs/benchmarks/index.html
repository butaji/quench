With the JIT off in every engine, Quench scores 1.49x to 2.57x (14 Nov 2026) the faster of Node --jitless and Bun on all 8 V8-v7 benchmarks, at 0.28x to 0.55x their peak memory on 7 of 8. On the broader JetStream 3 suite it scores 34.3 against Node 39.7 and Bun 32.2, at 28.5 MB peak memory against 110.1 MB and 47.7 MB. The JIT tiers and AOT have no published speed numbers yet.

Latest run, 27 November 2026 (commit 0505e2a326), geometric means over the 8 V8-v7 benchmarks: with the JIT off Quench scores 3,467 against 2,473 for Node --jitless and 1,737 for Bun (1.40x), at 10.0 MB against 24.6 MB and 57.1 MB peak memory (0.41x). Four of eight are at 1.5x or better; deltablue (0.99x) and earley-boyer (0.38x) are behind Node --jitless. With the JITs on, Quench's default mode scores 2,776 against 29,757 for Node and 35,588 for Bun (0.08x), at 17.3 MB against 71.8 MB and 52.5 MB (0.33x). The goal in every mode is 1.5x the score at 0.5x the memory. A shrink-only tier-order gate lists every program a faster tier runs in more instructions than the tier below: 26 on 27 November. Daily numbers are in the progress posts.

What is not measured yet

  • Deno. Not in our harness yet, so no Deno numbers are published.
  • JIT tiers. b-jit and u-jit are not yet competitive with V8 or JavaScriptCore with their JITs on; no comparison is published.
  • AOT executables. No speed numbers are published for AOT-compiled programs. The goals are within 5x of equivalent C, executables under 1 MB, and 1 ms startup. Strict AOT already compiles hello world to 4,896 bytes starting in 0.96 ms (25 November 2026).

Method

One 4-core Linux machine, each test pinned to a core. Peak memory is the maximum resident set size of the process. The harness and raw results are in the repository; every number on this page can be rerun from it.

About Quench

Quench is a JavaScript, TypeScript and WebAssembly runtime written in Rust. Test262: 53,353 passing, 0 failing. Interpreter, two JITs, and AOT to native executables. It is MIT licensed, early, and built from source with Cargo. Source: github.com/butaji/quench. Machine-readable summary: llms.txt.
