Progress, 26 November 2026: a hard gate for tier order, cheaper startup, AOT closed-world facts

Daily progress on Quench, the TypeScript, JavaScript and WebAssembly VM in Rust. 51 commits: a new gate fails any program a faster tier runs in more instructions than the tier below it, startup drops about 1.5 million instructions in the JIT modes, AOT images guess object shapes from the closed world, and a quadratic RegExp-on-rope case is gone. With the measured numbers, including where the JITs still lose.

Second daily post. It covers the 51 commits that landed on v2-merged between the previous post and 12:30 UTC on 26 November. Numbers are measured and name their commit; targets are labelled as targets.

The theme: make tier order a rule, not a hope

Quench's design promise is interpreter < b-jit < u-jit: each faster tier is a specialization of the one below it, so it should never do more work. Yesterday's post showed that the JIT modes do not deliver that yet. Today that became a gate instead of a chart.

A tier-order gate. A new tier-order step runs every C-parity kernel and every file of a named corpus, cold, under no-jit, b-jit, u-jit and default, and fails when a higher tier runs the program in more instructions than the tier under it (0.3% slack). Existing violations sit in a list that can only shrink.

The first recording is blunt, which is the point:

Crypto and navier-stokes are already in order. Each fix from here lowers a number that cannot go back up.

Cheaper startup in the JIT modes. Slot representation tracking now starts at the first compile instead of at VM start, so a run that never compiles never pays for it. Printing "hi" dropped from 13.18 to 11.68 million instructions under --b-jit and from 13.28 to 11.70 million in default mode, now below the interpreter-only mode (11.91 million). The lane stack's frame tables moved to zero-filled pages, another 0.1 million instructions and 50 to 190 KB of peak memory in every mode. Snapshots restore shapes and atoms as written, and builtins get their final attributes in one step. The target remains 1 ms-class startup in every mode.

b-jit rows stop calling the general step. A long series of commits gives each b-jit row's slow arm a typed helper (closures, calls, allocation, throws, operators, array literals, locals and captures) instead of falling back to the generic interpreter step. A trace now names each AOT image record that still calls the general step, so the remainder is a list.

AOT closed-world facts. The closed world proves call targets again and lets an image body inline frames. Image field reads and int32, object and null field stores guess object shapes from the constructors the program actually has, and stay in place. A fix stopped o[k] from counting as dynamic source, which had switched closed-world facts off on every V8 v7 file. Static executables now link their RegExp searches.

Correctness and cost fixes. A RegExp run repeatedly on a rope (a lazily concatenated string) flattened it on every call, which made such loops quadratic; it is now flattened once. A Splay miscompile in the u-jit, where a helper call rebound its region's stacks, is fixed. BigInt typed-array reads and BigInt comparisons now read each cell once: the data-structure B-tree's get_hit went from 45.5 to 39.1 thousand instructions per operation without the JIT.

One change was reverted. Warming the enclosing loop when an inner loop trips its counter was reverted until the R-tree benchmark is back in order. A change that makes one benchmark worse does not stay in.

Measured

The newest published V8 v7 comparison is still the one from yesterday's post (commit 37fbb34909): with the JIT off, 1.42x the best of Node and Bun at 0.45x the memory; with the JITs on, 0.10x the score of Bun at 0.53x the memory. The target in every mode is 1.5x the score at 0.5x the memory.

The data-structure suite has its first instruction counts (commit 6912335172), as a multiple of the instructions the C version needs per operation. This is the honest starting line; the goal is to land near 3x C.

Next

Lower the tier-order list, starting with b-jit over the interpreter on V8 v7. Keep moving b-jit slow arms to typed helpers until the general-step list is empty. First full data-structure sweep with time and peak memory against C, Node and Bun.
