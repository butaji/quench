Progress, 28 November 2026: AOT learns the class of every object; tier policy stops reading the clock

Daily progress on Quench, the TypeScript, JavaScript and WebAssembly VM in Rust. A quieter day of 19 commits: the AOT compiler now solves the class of every object, field and this in the closed world and inlines every call it can prove, tier and memory policy depend on the program instead of the clock, and one slot representation holds in every mode. V8 v7 numbers at the newest commit.

Fourth daily post. A quieter day: 19 commits on v2-merged between yesterday's post and 20:48 UTC on 27 November, and nothing new overnight. Numbers are measured and name their commit; targets are labelled as targets.

The theme: AOT knows what every object is

An ahead-of-time compiler sees the whole program, so it should never have to guess what kind of object a field access touches. Today it stopped guessing.

A class on every fact. The AOT fact pass now records a class on every fact it has: each new, each this, parameters, return values, array elements and fields per class. One closed-world type solve gives the class of every named field access's object and of each function's this. So a method read off a field is known to be that class's method.

Typed fields in the image. Image field reads use those types. A construction's objects are guarded by a single layout id fixed at link time, and a layout-guarded access that misses leaves the image instead of probing and rejoining. Method reads take the method the image linked, and a watch on the prototype value retires that choice if the program ever changes it.

Inline everything proven. An image unit inlines every call the closed world proves. A callee that cannot restart leaves into its materialized frame, and a leave inside an inlined frame rebuilds its activation from the callee register. A function keeps one inlined view instead of one per call site; raytrace had been storing about 150.

Also landed

  • Tier and memory policy read the program, not the clock. Decisions that depended on wall time now depend on what the program did, so the same program takes the same path on every run and every machine.
  • One slot representation in every mode. Float slots are no longer a per-mode default, and slot types survive any compile or image install without a mode check.
  • Builds. Staged steps compile one instance per operation kind, the fast dispatch root is split across six modules, and a structural edit to stencil sources rebuilds only the shards it reaches.
  • Cranelift rematerializes symbol addresses where they are used instead of holding them in registers.
  • Startup gate. One 2% limit for every row, with no environment switch.

The interpreter's own score rose again, from 3,467 to 3,585. Node's --jitless score also came in higher on this run, so the ratio is flat at about 1.4x, short of the 1.5x target. Memory stays under the 0.5x target. With the JITs on, Quench is at 0.08x the score of Bun, against the same 1.5x target; the 26-entry tier-order list is unchanged.

Startup at the same commit: printing "hi" takes about 8.6 ms wall time without the JIT and 8.9 ms with b-jit (9.2 ms yesterday). The target is 1 ms-class startup in every mode and AOT executables under 1 MB starting in 1 ms. Strict AOT already does that for hello world: 4,896 bytes, 0.96 ms.
