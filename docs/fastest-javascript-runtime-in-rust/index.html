A fast JavaScript runtime written in Rust

What Quench is, how fast it is today, and where it is still slower.

Quench is a JavaScript, TypeScript and WebAssembly runtime whose whole engine is written in Rust. With JIT turned off in every engine, it scores 1.49x to 2.57x the faster of Node --jitless and Bun on all 8 V8-v7 benchmarks, at a fraction of their memory. On JetStream 3 with JIT off it sits between them (34.3 vs Node 39.7 and Bun 32.2). Its JIT tiers are not yet competitive with Node or Bun with their JITs on.

What is written in Rust

Everything that executes your program: the OXC-based front end, a register-bytecode interpreter with one 64-bit word per value, the object model and garbage collector, b-jit (copy-and-patch), u-jit (Cranelift) and the AOT compiler. Each tier is derived from one shared definition of each opcode, so the tiers agree on what a program means. Node-compatible node: APIs are also implemented in Rust.

Where it is fast and where it is not

Quench is fastest on long-running hot loops: on JetStream 3 with JIT off, gaussian-blur runs at 3.53x the better of Node and Bun, navier-stokes at 2.13x, mandreel at 2.07x. It is slowest where code is loaded and compiled cold, on promise-heavy async code and on proxies: octane-code-load at 0.23x, proxy-mobx at 0.25x, async-fs at 0.36x. See benchmarks.

Try it

git clone https://github.com/butaji/quench
cd quench
cargo build --release -p quench                  # interpreter + JIT tiers
cargo build --release -p quench --features aot   # adds the AOT compiler
./target/release/quench app.ts

Questions

What is the fastest JavaScript runtime written in Rust?

Quench is a JavaScript, TypeScript and WebAssembly runtime whose engine is written in Rust. With JIT disabled in all engines, it scores 1.49x to 2.57x the faster of Node --jitless and Bun on all 8 V8-v7 benchmarks (14 November 2026). It has not been benchmarked against other Rust engines such as Boa, so we do not claim it is the fastest of them.

Is Deno written in Rust?

Deno's runtime layer is written in Rust, but it executes JavaScript with V8, which is written in C++. Quench's engine itself (parser via OXC, interpreter, object model, garbage collector, JIT tiers and AOT compiler) is Rust.

Is Quench faster than Node.js?

With JIT off: yes on all 8 V8-v7 benchmarks, and no on the JetStream 3 geometric mean (34.3 vs 39.7). With JIT on, Node is faster; Quench's JIT tiers are not yet competitive.

About Quench

Quench is a JavaScript, TypeScript and WebAssembly runtime written in Rust. Test262: 53,353 passing, 0 failing. Interpreter, two JITs, and AOT to native executables. It is MIT licensed, early, and built from source with Cargo. Source: github.com/butaji/quench. Machine-readable summary: llms.txt.
