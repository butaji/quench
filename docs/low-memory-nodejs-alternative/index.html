A Node.js alternative with low memory use

Peak memory measured against Node and Bun, including the tests where Quench uses more.

Quench is a JavaScript and TypeScript runtime with Node-compatible APIs, written in Rust. With JIT off, its geometric-mean peak memory on 56 JetStream 3 tests is 28.5 MB, against 110.1 MB for Node --jitless and 47.7 MB for Bun: 26% of Node's and 60% of Bun's. It has the lowest peak memory of the three on 51 of the 56 tests. It is early and has no packaged releases.

Where Quench uses more memory

On V8-v7 splay Quench peaks at 58.7 MB against Bun's 54.9 MB. On large startup workloads it can use much more: babylonjs-startup-es6 peaks at 562 MB against Bun's 339 MB, because programs from earlier iterations stay reachable and an idle function costs about 2.8 KB. Inside the 56 compared JetStream 3 tests, Quench is above the lowest engine on Sunspider, mandreel, the two doxbee tests and babylonjs-scene. Making function bodies lazy is the current fix.

Why it is small

One 64-bit word per value, compact object layouts, a register-bytecode interpreter, and compiling a function body only on its first call.

Try it

git clone https://github.com/butaji/quench
cd quench
cargo build --release -p quench                  # interpreter + JIT tiers
cargo build --release -p quench --features aot   # adds the AOT compiler
./target/release/quench app.ts

Questions

What is a Node.js alternative with low memory use?

Quench is a JavaScript, TypeScript and WebAssembly runtime with Node-compatible APIs, written in Rust. With JIT off, its geometric-mean peak memory on JetStream 3 is 28.5 MB, against 110.1 MB for Node --jitless and 47.7 MB for Bun (17 November 2026).

How much memory does Quench use for a small program?

On V8-v7 with JIT off, richards peaks at 6.4 MB, deltablue at 6.9 MB and raytrace at 7.1 MB, where Node --jitless needs 43.5 to 50.1 MB (14 November 2026).

Can Quench replace Node.js today?

Not for production yet. Quench has no packaged releases and its Node API compatibility is still being built out, so expect gaps.

About Quench

Quench is a JavaScript, TypeScript and WebAssembly runtime written in Rust. Test262: 53,353 passing, 0 failing. Interpreter, two JITs, and AOT to native executables. It is MIT licensed, early, and built from source with Cargo. Source: github.com/butaji/quench. Machine-readable summary: llms.txt.
