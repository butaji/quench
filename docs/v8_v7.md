# V8_v7 measurement

Run only after the [stencil infrastructure gate](stencil-jit-implementation-spec.md)
and initial micros correctness validation. This is a separate end-to-end suite,
not a replacement for semantic tests or micros.

## Run

From the repository root, use an explicitly identified, uninstrumented artifact:

```sh
cargo build --profile production -p quench-node
node tools/record-v8-evidence.cjs --binary target/production/quench-node --runs 3 --timeout-ms 300000 --out target/v8-new-attempt.json
```

Choose a new output filename for every attempt; this tool does not enforce
non-overwrite. It creates the parent directory and retains raw samples beside
the derived record. Capture source/dirty state and build flags when building,
not just when recording. See [performance lanes](performance-lanes.md).

For a targeted run add `--only richards,deltablue`. The runner covers Richards,
DeltaBlue, Crypto, RayTrace, EarleyBoyer, RegExp, Splay and NavierStokes.
A subset is not a whole-suite score. Timeout is a reported failure, not zero cost.

## Interpret

- Higher suite score is better; compare complete geometric aggregates and each
  fixture under matched machine/build/run conditions. A fixed historical target
  is not portable between machines.
- The runner's `valid` means every process exited successfully, avoided timeout
  and emitted a score. It is not comprehensive JS conformance.
- `output_equal` compares stdout that includes engine-dependent timing scores.
  Equality is neither required for a valid scored run nor a substitute for
  independent semantic tests and the suite's own assertions.
- The current raw runner records score and wall time, **not peak RSS**. Do not
  attribute an RSS result to this tool. Collect separately identified external
  memory evidence; the micros harness has fixed-work and lifecycle measurements.
- Retain raw failures, per-fixture ratios and missing data. No win is established
  by one synthetic case or an incomplete aggregate.
- Review generalization and regressions using [benchmark integrity](benchmark-integrity.md).

## Diagnostics

Use a separate trace artifact. The existing
`tools/instruction-category-ledger.mjs` accepts `--engine`, repeated
`--fixture` or `--corpus`, `--out`, `--compare` and `--facts-log`.
Set `QUENCH_EXEC_TRACE=1`; the artifact must contain `execution-trace`.

Supply runnable standalone scripts. V8_v7 fixture files need their suite wrapper;
new micros `cases/*.js` need their registration/payload harness. Scanning the
micros root also includes support scripts, so it is not a valid complete corpus
selection. Use micros `diagnose` for the new experiments.

A ledger ranks observed counters, not CPU-time shares or independent events.
Corroborate hypotheses with native sampling and matched uninstrumented runs.
Historical profiles and scores are available in Git; rerun before treating a
previous no-go or bottleneck as current.
