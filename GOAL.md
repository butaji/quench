# Goal

Implement the interpreter rewrite tracked in [the Linear project](https://linear.app/todoxapp/project/quench-abb744c79c4e/overview),
using the pinned `../v2` runtime architecture while preserving Quench's
observable ECMAScript, Node, and Wasm behavior.

The Linear project is the source of truth for status, dependencies, conformance gates,
and Apple M4 performance evidence. See [the documentation index](docs/README.md)
for stable commands and contracts.
