# 03: Clean the interpreter oracle and repository

## Outcome

Establish a warning-free, test-clean repository and trustworthy legacy interpreter oracle before importing the replacement.

## Current gap

The oracle now passes its maintained semantic suite. Remaining cleanup is the
warning/dead-code audit, stale compatibility wording, and the final repository
smoke matrix before importing the pinned replacement.

## Dependencies

## Scope and implementation sequence

1. Fix Atomics to reject every non-shared typed-array view before load/store/notify effects and verify against Node. (Done; focused regression passes.)
2. Move the release-only slot timing probe to benchmark tooling or delete it if it has no consumer; leave no ignored correctness test. (Done; deleted.)
3. Resolve all Rust/build warnings, unused dependencies, dead modules, broken local links, and stale native/task claims.
4. Update the task coherence checker for schema 2, two-digit headings, retained `done` tasks, arbitrary lane dependencies, nullable terminal `next_task`, and removal of the 342-profile requirement.
5. Document the temporary interpreter-oracle architecture without presenting it as the final runtime.
