# 03: Clean the interpreter oracle and repository

## Outcome

Establish a warning-free, test-clean repository and trustworthy legacy interpreter oracle before importing the replacement.

## Current gap

The baseline has a failing non-shared Atomics test, an ignored timing probe, stale queue/JIT documentation, obsolete dependencies, and a coherence checker coupled to the removed native contract.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

1. Fix Atomics to reject every non-shared typed-array view before load/store/notify effects and verify against Node.
2. Move the release-only slot timing probe to benchmark tooling or delete it if it has no consumer; leave no ignored correctness test.
3. Resolve all Rust/build warnings, unused dependencies, dead modules, broken local links, and stale native/task claims.
4. Update the task coherence checker for schema 2, two-digit headings, retained `done` tasks, arbitrary lane dependencies, nullable terminal `next_task`, and removal of the 342-profile requirement.
5. Document the temporary interpreter-oracle architecture without presenting it as the final runtime.

## Verification

Run formatting checks, warning-denied workspace check/test/clippy, JavaScript lint, task/document coherence, Node smoke, Test262 smoke, and Wasm smoke.

## Definition of done

- All checks pass with zero warnings, failures, or ignored correctness tests.
- No tracked file refers to a deleted native authority or missing task path.
- The repository is clean before the reference import.

## Performance evidence

None required.
