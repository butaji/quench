# 03: Clean the interpreter oracle and repository

## Outcome

Establish a warning-free, test-clean repository and trustworthy legacy interpreter oracle before importing the replacement.

## Current gap

The oracle now passes its maintained semantic suite. Remaining cleanup is the
warning/dead-code audit, stale compatibility wording, and the final repository
smoke matrix before importing the pinned replacement.

## Dependencies

## Scope and implementation sequence

1. Fix Atomics to reject every non-shared typed-array view before load/store/notify effects and verify against Node. (Done; focused regression passes.)
2. Move the release-only slot timing probe to benchmark tooling or delete it if it has no consumer; leave no ignored correctness test. (Done; deleted.)
3. Resolve all Rust/build warnings, unused dependencies, dead modules, broken local links, and stale native/task claims.
4. Update the task coherence checker for schema 2, two-digit headings, retained `done` tasks, arbitrary lane dependencies, nullable terminal `next_task`, and removal of the 342-profile requirement.
5. Document the temporary interpreter-oracle architecture without presenting it as the final runtime.

## Verification

Run formatting checks, warning-denied workspace check/test/clippy, JavaScript lint, task/document coherence, Node smoke, Test262 smoke, and Wasm smoke.

Current evidence: local Node confirms `Atomics.load`, `Atomics.store`, and
`Atomics.notify` reject non-shared `Int32Array` views with `TypeError`; Quench's
focused Atomics regression and maintained runtime suite are green.

The post-import lint pass applied compiler-proven unused-binding, import, and
mutability fixes across the legacy runtime and Node host; the maintained runtime
suite still passes 705 tests with no failures or ignored tests. Remaining
warnings are primarily dead compatibility modules and visibility/deprecation
cleanup, not failed compilation paths.

The latest oracle cleanup removes deprecated OpenSSL and elliptic-curve calls,
unreachable crypto/inspection branches, private-interface leaks, ignored
results, and macro documentation/import warnings; the Node library suite
passes 16 tests. The warning-denied gate remains open while dormant legacy

reports warnings from the dormant legacy machine/stencil compatibility shell.

task 03 remains active until the warning-denied check is clean.

passes its all-target, memory-profile, and aggregate-profile checks without
diagnostics. Its lint gate also passes `cargo clippy --all-targets -- -D
warnings`; the legacy build now emits the generated operation-variant contract

artifacts. The default and all-feature runtime-next test/clippy matrices are
green. The remaining warning surface is confined to the legacy oracle and host
