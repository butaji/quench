# 003: Define the canonical operation fact schema

- **Theme:** deegen_codegen
- **Executor:** codex
- **Depends on:** 001, 002

## Scope
- crates/quench-runtime/src/facts.rs
- crates/quench-runtime/src/ir.rs

## Deliverables
- Represent operation identity, operands, result shape, effects, control-flow exits, guards, fallback, and observability as data
- Use Proven, Guarded, and Unknown for specialization facts
- Assign stable operation IDs and validate duplicate or incomplete declarations

## Acceptance
- The schema has one representation for each semantic fact
- Unknown facts select complete ordinary behavior without allocating optimizer state

## Non-goals
- A second AST or a second runtime crate
