re-wiring rather than a from-scratch rebuild.

## Non-goals
- SO_REUSEPORT-based real kernel-level load balancing across OS processes if
  quench-node's process model doesn't have separate OS processes — match
  observable JS semantics, not the kernel mechanism
- Node-private `internal/cluster/*` imports and arbitrary inherited file
  descriptor numbers across separately spawned processes; the single-process
  model has no second OS process into which an already-bound fd can be
  transferred.
