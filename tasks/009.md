# 009: Unify JS and Wasm frontend lowering on the operation catalog

- **Theme:** deegen_codegen
- **Executor:** codex
- **Depends on:** 006

## Scope
- crates/quench-runtime/src/wasm
- crates/quench-runtime/src/hir.rs
- crates/quench-runtime/src/ir.rs

## Deliverables
- Lower both frontends into the same fact-checked operation representation where semantics overlap
- Keep Wasm linear-memory and trap behavior explicit at the effect boundary
- Reject unsupported operations instead of inventing a second semantic universe

## Acceptance
- Shared operations have one semantic declaration and frontend-specific adapters only where required
- Wasm tests preserve traps, memory ordering, and host effects

## Non-goals
- A Wasm-specific JavaScript runtime
