# 13: Port arrays, buffers, typed arrays, and Atomics

## Outcome

Implement indexed collections and shared memory with exact backing, species, detachment, and atomic semantics.

## Current gap

Current committed staging gaps include ArrayBuffer/TypedArray species and realm
identity, backing error order and bit-preserving slices. The current frontier is owned by
[task 20](20.md#open-stage-114-failures). Historical passing observations on
uncommitted builds do not qualify the production revision.

Array construction now uses canonical realm intrinsics and shared
LengthOfArrayLike conversion. ArrayCreate owns the ordinary length limit; custom
species receive the converted length without an earlier rejection. Array.from
and slice perform their final observable length Set through the shared operation,
while TypedArray.from retains its separate contract.
[Committed construction qualification](evidence/task13-array-construction.json)
retains 4,604/4,649 distinct affected passes, gains four staging cases and has
zero regressions. All 50 normal/generic Node observations match. Staging Array
passed 89/90 at that revision.
[Length/property qualification](evidence/task13-array-length-authority.json)
now closes `length-01.js`: 7,046/7,046 affected cases and 90/90 staged Array
cases pass with one gain and zero regressions. All 44 Node observations match.
Array length is recognized by shared own-property lookup; default attributes
have one named owner, and writes, reflection and integrity use that authority.
Foreign Array prototypes derive length from array storage. Arguments objects
keep their distinct length contract. These bounded results do not close task
13 or Stage A.

[TypedArray integrity qualification](evidence/task13-typed-array-integrity.json)
routes seal/freeze and their queries through the existing ordered descriptor
algorithms. The affected inventories retain 5,255/5,264 passes, gain both staged
integrity cases and have zero regressions. Nine selected failures remain,
including three official copyWithin detachment cases. Ordinary Node controls
improve from 98 to 108 of 108 matches; twenty other observations retain explicit
Node fast-path differences in queries and partial named-property mutations.
The pinned descriptor contract is preserved; this does not close Node compat
qualification, task 13 or Stage A.
