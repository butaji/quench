# 13: Port arrays, buffers, typed arrays, and Atomics

## Outcome

Implement indexed collections and shared memory with exact backing, species, detachment, and atomic semantics.

## Current gap

V2 arrays are dense/sparse ES5 containers; full Quench behavior includes holes, exotics, ArrayBuffer variants, DataView, typed arrays, resizable/growable backing, and Atomics.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

Port Array construction/mutation/iteration/species, arguments arrays, ArrayBuffer/SharedArrayBuffer lifecycle, transfer/detach/resize, DataView, every typed-array constructor and method, numeric conversions, and Atomics including wait/notify/waitAsync. Use explicit external backing owners and generation stamps.

## Verification

Run all corresponding Test262 families plus overlap, detach-during-coercion, species re-entry, holes/inheritance, endianness, shared/non-shared rejection, worker visibility, and GC/backing lifetime tests.

## Definition of done

- Indexed properties obey object descriptors and array/typed-array invariants.
- Detached, resized, and shared backing transitions are validated at each effect boundary.
- The Atomics failure fixed in task 03 remains covered in the new runtime.

## Performance evidence

Report dense/sparse/backing bytes, transitions, and array workload Score/RSS.

## Implementation evidence

The next VM now exposes `Array.isArray` through the native builtin table and
checks the heap cell kind directly, distinguishing dense arrays from ordinary
objects and primitives. Array `slice` now preserves dense and sparse indexed
values for ordinary arrays and is used by array destructuring rest bindings.
Slice bounds use the shared numeric coercion path, including string and
fractional arguments with truncation toward zero.
`Array.prototype.includes` now uses the collection SameValueZero authority,
including `NaN` and `undefined` holes, with coerced `fromIndex` bounds.
`Array.prototype.join` now preserves separator positions for holes and
`undefined`/`null`, while routing other elements through canonical string
conversion. `Array.prototype.concat` now allocates a non-mutating dense result,
flattening array arguments one level and preserving scalar arguments in order.
`Array.prototype.flat` now materializes a non-mutating dense result with
numeric depth coercion and recursive array flattening.
Full typed-array/backing-store and Atomics parity remain on the critical
conformance path.
