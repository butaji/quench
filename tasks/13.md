# 13: Port arrays, buffers, typed arrays, and Atomics

## Outcome

Implement indexed collections and shared memory with exact backing, species, detachment, and atomic semantics.

## Current gap

Stage A remains open. Current gaps include ArrayBuffer/TypedArray species and
realm identity, constructor error ordering and the official
copyWithin timeouts. [Task 20](20.md#open-stage-114-failures) owns the committed
frontier; observations on uncommitted builds do not qualify production.

Array construction uses canonical realm intrinsics and shared LengthOfArrayLike.
ArrayCreate owns the ordinary length limit; custom species receive the converted
length. Array.from and slice perform the final observable length Set. Array
length derives from existing dense/sparse storage; reflection, writes and
integrity share its named default descriptor. Arguments keep their separate
length contract. TypedArray integrity uses the ordered descriptor algorithms;
Node fast-path query and partial-mutation differences remain explicit.

TypedArray copying preserves exact backing bytes for equal kinds. copyWithin
handles overlap; set snapshots aliased sources when needed; slice copies forward
through aliased species views. These operations retain their distinct coercion,
bounds and species contracts. Species and set derive numeric content from the
same TypedArrayKind classification. Writable species cannot return immutable
backing, including an alias of the source.

[Slice qualification](evidence/task13-typed-array-slice.json) closes
`slice-bitwise-same.js`, while the official
immutable-alias overlap fixture loses its former pass. Its harness expects writes
into immutable backing, conflicting with the destination fixture and proposal.
The direct control proves the former exception mutated immutable bytes. Preserve
both fixtures and the failing comparison; this is not zero-regression evidence.
Local Node lacks transferToImmutable, so immutable controls use the proposal
contract.

[Realm API qualification](evidence/task20-realm-host-api.json) closes
`iterator-next-with-detached.js` and `set-wrapped.js`. Primary and child realm
APIs derive from one installer and the host's declared capability/binding names.
All 230 realm-named fixtures and 44 Node realm observations pass in that bounded
qualification; ordinary hosts expose no undeclared realm API bindings.

Current [buffer property qualification](evidence/task13-buffer-property-authority.json)
closes `constructor-ArrayBuffer-species-wrap.js`. Primary and child buffer realms
share constructor/prototype installation. Ordinary accessors own property reads;
the virtual reader and its cache bypass are removed. Species getters retain
distinct identities while sharing implementation. The affected union passes
3,362/3,367 with one gain and zero regressions; all 171 Node observations match.
The selected TypedArray inventory passes 1,537/1,542. Five failures remain:
three official timeouts, the immutable conflict and `constructor-buffer-sequence.js`.
TypedArray allocation realm ownership and prototype/error ordering remain open.
