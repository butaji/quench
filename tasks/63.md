# 63: Preserve implemented Node stack and error diagnostics

## Outcome

Preserve the stack traces and error diagnostics observed by task 19’s frozen
implemented Node cases. Derive required positions and frame views from one
authority. Additional V8 extensions, frame kinds and formatting strategies are
outside this task unless a required case or internal invariant needs them.

## Current gap

Audit the observations below against the frozen inventories before implementing
changes. Fix only remaining required behavior; existing correct paths need no
replacement. Historical observations are not proof of a current failure.

- The next core's `stack` getter returns the error's string form, with no frames
  (`crates/quench-runtime-next/src/vm/error.rs`, `error_stack_getter`).
- Task 05's residual contract has no table that maps instruction positions back
  to source, so no frame can name a line or column.
- Legacy Quench implements `Error.captureStackTrace` and the related V8
  extensions (`crates/quench-runtime/src/builtin_meta/error.rs`), and
  `quench-node` depends on them. Tracked node-compat fixtures read `.stack` and
  call `captureStackTrace`, and Node's uncaught-error output needs the same
  location data.
- Test262 does not observe stack traces, so no current ratchet catches the gap.
  Without this task it would first appear late, as task 22 failures.

## Dependencies

See this task's `depends_on` in [index.json](index.json). Tasks 21/22 require
the diagnostics observed by the frozen implemented cases, not completion of this
task's optional mechanisms. Use the shared activation representation for any
required frame walk.

## Required scope and optional mechanisms

Stage A implements only the behavior observed by the pinned Test262 inventory or
task 19's frozen implemented Node cases, and the internal lifecycle/safety
invariants needed to run them on the single VM. The mechanisms below are
implementation options within that scope, not a requirement to expand Node
coverage or finish a broader host/architecture rewrite.

1. Extend the residual contract (task 05) with a compact, versioned position
   side table from instruction ranges to source spans, emitted by the OXC
   specializer (task 10) and by dynamic compilation (task 18). Change the
   residual format fingerprint. Keep positions out of the eight-byte instruction
   and off the dispatch path.
2. Define one frame-walk operation over activations, including suspended
   generator and async frames, native builtin frames, and Wasm frames (task 37).
   Stack capture, `captureStackTrace`, and host diagnostics all use it.
3. Capture frames lazily. Record the minimal frame data when the error is
   created, bounded by `Error.stackTraceLimit`, and format the string on first
   read. Formatting follows V8's layout: function name, `new`, method receiver,
   `async` frames, `eval` origins, and file:line:column.
4. Implement `Error.captureStackTrace(object, constructorOpt)`,
   `Error.stackTraceLimit`, and the
   `Error.prepareStackTrace(error,
   callSites)` hook with CallSite objects,
   matching Node's descriptors and property order.
5. Expose source location of a thrown value through the host facade (task 43),
   so `quench-node` can print uncaught errors with the source line and caret.

## Verification

Compare stack strings, CallSite results, descriptors, and uncaught-error output
with the local Node oracle for plain calls, constructors, methods, getters,
`eval`, `Function`, modules, generators, async functions, and Wasm frames. Rust
regression tests cover the position table round trip and frame truncation. Run
affected Test262 stages plus compare-runs; retain units only for internal
invariants or scenarios absent from the pinned suites.

## Definition of done

- Frozen implemented Node cases observing stacks and error diagnostics match the
  local Node oracle, including descriptors and uncaught output.
- Required source positions and frame traversal each have one authority.
  Internal serialization and lifecycle checks pass where these are changed.
- Additional frame kinds, V8 extensions and lazy formatting are not separate
  gates unless required by the frozen cases or internal correctness.
