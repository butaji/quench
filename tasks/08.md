# 08: Rebuild objects, shapes, descriptors, and caches

## Outcome

Provide one ECMAScript object/property authority built on v2's immutable shapes and bounded inline caches.

## Current gap

V2 shapes encode ordered names and data slots only; complete semantics require attributes, accessors, prototypes, exotic behavior, mutation invalidation, and exact own-key ordering.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

1. Define immutable shape entries from ordered `PropertyKey`, slot, and descriptor attributes, with transition interning and dictionary fallback.
2. Implement canonical internal methods for get/set/define/delete/has/ownKeys/prototype/extensibility; all specialized paths call or exactly guard these operations.
3. Separate ordinary storage from exotic dispatch while preserving one object identity and prototype representation.
4. Extend field/method caches to monomorphic, bounded polymorphic, and megamorphic states keyed by shape/prototype/callable facts.
5. Invalidate or revalidate caches on descriptor, prototype, callable, backing, replacement, and collection transitions.

## Verification

Cover descriptor matrices, accessors and re-entry, integer/string/Symbol ordering, prototype mutation, delete/re-add, non-extensible objects, dictionary transitions, cache churn, and stale-handle reuse.

## Definition of done

- Ordinary and exotic objects share one internal-method contract.
- Cache hits preserve exactly-once effects and have an observable generic fallback.
- Object identity and property authority are not duplicated in adapters.

## Performance evidence

Report shape/property bytes, cache hit/miss/promotions, transition counts, and property-heavy workload effects.

## Implementation evidence

The prototype transition now has one named mutation boundary: it rejects cycles
before changing the graph and invalidates field and method caches after a valid
prototype replacement. A warmed-cache regression verifies reads follow the new
prototype, and the cycle path produces the required failure. Dictionary
fallback work remains pending for this task.

Shape keys remain the immutable authority while a derived atom-to-slot index is
rebuilt at each interned transition and reset with the realm shape table. The
index is used by ordinary get/set/delete/enumerability paths and has focused
alignment coverage, avoiding duplicate property-name authorities.

The shape authority is now represented by one immutable `Shape` record: ordered
keys and its derived atom-to-slot index travel together through every shape
transition. Realm teardown clears the shape table as one unit, and object
lookup, JSON enumeration, and static key ordering all read that same record;
there is no parallel key/index array to drift.

The canonical descriptor transition now rejects mixed data/accessor fields,
rejects kind changes on non-configurable properties, and permits configurable
accessor-to-data replacement for ordinary and indexed array properties. The
regression and local Node oracle agree on the observable values and errors;
indexed-exotic descriptor folding remains pending.

`Object.defineProperties` now snapshots own descriptor keys, routes each entry
through the same `defineProperty` authority, and supports string and Symbol
keys without a parallel mutation path. `Object.create` now consumes its
optional descriptor map through that same route.

Symbol descriptors remain in one `PropertyKey`-indexed side table while
ordinary string descriptors are shape-owned. The key namespace is carried by
the key value itself, so GC retention, integrity transitions, deletion, proxy
invariants, and accessor metadata cannot drift within the exotic path; the
existing symbol and descriptor regressions continue to pass.

Ordinary string-property descriptor attributes now travel with the immutable
shape record. Shape transitions clone the descriptor vector, descriptor
redefinition publishes a new shape and invalidates derived caches, and the
canonical accessor/write/enumerability paths read that shape authority before
falling back to symbol or indexed-exotic side tables. Shape-held accessor
values are included in the VM root scan.
