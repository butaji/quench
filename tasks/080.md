# 080: Collapse identity MIR into HIR

`MirFunc` is a type alias for `HirFunc`, and `mir::specialise` is an identity
function. Remove the semantic layer that currently adds naming without data.

## Plan

- Replace internal `MirFunc`/`mir::specialise` uses with `HirFunc`.
- Remove the identity module and its identity-only tests.
- Audit the unused NIR/FIR/DIR aliases; remove them or represent layer facts in
  one explicit type/value, not parallel aliases.
- Keep a deprecated re-export only if a public API requires compatibility.

## Acceptance

Interpreter and instance behavior are identical, no second IR is introduced,
and runtime tests plus compile-time API checks pass.
