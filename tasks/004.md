# 004: Implement the fact-to-VM macro DSL

- **Theme:** deegen_codegen
- **Executor:** codex
- **Depends on:** 003

## Scope
- crates/quench-runtime/src
- crates/quench-runtime/build.rs

## Deliverables
- Add one declarative vm_op! macro declaration that emits operation IDs, metadata, operand decoding, and fallback references
- Emit a uniform opcode-to-handler table while keeping semantic bodies handwritten
- Make generated names, widths, and tables compile-time derived from the declaration
- Keep semantic bodies as small handwritten functions selected by generated metadata

## Acceptance
- Adding an operation changes one declaration and regenerates all mechanical views
- No attribute or proc-macro declaration layer is required
- Generated output has no source-code or benchmark inspection

## Non-goals
- Generating a JIT backend
