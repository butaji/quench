# 081: Unify native plan lifecycle state

`machine.rs` repeats the same local/shared publication, invalidation, fallback,
retirement, and cache transitions across several installed-entry enums and
native plans.

## Plan

- Specify the common state machine (`Unpublished`, local, shared, invalidated)
  and its ownership/lease invariants.
- Introduce a generic installed-entry/plan lifecycle with typed ABI adapters.
- Migrate binary, truthiness, nullish, unary, and related plans incrementally.
- Preserve exact stale-entry rejection, rooting, reentry, and fallback behavior.

## Acceptance

Lifecycle transitions have one implementation and explicit tests cover local,
shared, retirement, cache eviction, reentry, and ordinary fallback semantics.
Measure code size and hot-path behavior before/after; do not optimize by
weakening guards.
