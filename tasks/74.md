# 74: Fold static control flow and hoist pure loop invariants

## Plan scope

Stage B candidate after task 86 verifies Stage A. Select this work only for a

Use affected-stage checks plus compare-runs during changes. The current

## Outcome

The residual contains no branch that has a static condition, no code that
cannot be reached, and no exception handler around a body that cannot throw.
Loops are identified as natural loops, and pure operations whose inputs do
not change in the loop run once in the preheader.

## Current gap

Constant folding stops at values. A branch on a folded constant still
dispatches, code after `return` or `throw` is lowered, and every `try` sets
up a handler. No pass identifies loops, so task 57's induction-variable
ranges have no loop structure to attach to.

## Scope and implementation sequence

Steps 5–8 were proposed in pinned v2 (tasks 69, 259, 293, 312–314) and are
unmeasured there.

1. Remove branches whose condition is a static constant, and the code that
   becomes unreachable. Early errors are reported before this step, as the
   spec requires, so removed code still reports them.
2. Build the natural-loop forest from the existing residual control-flow graph, and give task 57's range analysis loop headers and induction
   variables.
3. Hoist an operation to the loop preheader only if it is graded `pure` for
   its proved operand kinds, cannot throw, and has loop-invariant inputs.
   Property reads are never hoisted here, because they belong to guarded
   caches.
4. Omit handler setup for a `try` body whose union of effect sets excludes
   `throws`. `finally` semantics and completion values are unchanged.
5. Thread jumps to unconditional jumps, and lower dense `switch` statements
   and integer-keyed `if` chains to jump tables. The density threshold comes
   from the paired gate.
6. Remove bounds checks on indexed element access where task 57's ranges
   prove `0 ≤ i < length` and nothing in between can change the length.
7. Number pure operations within extended basic blocks (superlocal value
   numbering), and reuse results instead of recomputing them.
8. Turn self tail calls into loops only where the recursion is not
   observable: the function is strict or never reads `arguments.callee` or
   `caller`, and task 76's virtual frames keep stack traces and the
   stack-overflow depth identical.
