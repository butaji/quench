# 013: Wire call-site guard state to the declared Callable fact

- **Theme:** deegen_codegen
- **Executor:** codex
- **Depends on:** 007

## Scope
- crates/quench-runtime/src/quickening.rs
- crates/quench-runtime/src/facts.rs
- crates/quench-runtime/src/ir.rs

## Deliverables
- Add a QuickeningSite observation path for OperationGuard::Callable, mirroring the existing Shape path
- Guard on eligible function-object identity; other callable kinds remain on the complete gateway rather than acquiring a partial cache
- Reach Call sites already marked guard-eligible in the operation catalog so Proven/Guarded/Unknown facts apply uniformly to calls and property access
- Preserve the existing miss-to-fallback contract: a callee-identity miss returns to the complete ordinary call path

## Acceptance
- A call site that always invokes the same function/native object specializes; a call site with a changing callee runs ordinary semantics
- No dispatch decision reads a function's name, source text, or declaration site — only its runtime identity
- Differential tests cover monomorphic, polymorphic, and identity-changing call sites

## Non-goals
- Speculative inlining or a call-target JIT
