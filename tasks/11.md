# 11: Port core language, function, and class semantics

## Outcome

Implement the complete language execution core on the new frames, environments, objects, and residual compiler.

## Current gap

V2 lacks modern bindings, parameter forms, classes, private environments, many completion paths, and the observable edge cases already implemented by legacy Quench.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

Port declaration instantiation, `var`/lexical/TDZ bindings, parameters, destructuring/rest/spread, all statements and control completions, functions/arrows, calls/constructors, `this`/`super`/`new.target`, classes/fields/static blocks, private environments, direct eval, `with`, and their early errors. Port proven algorithms but rewrite storage and activation around the new authorities.

## Verification

Run focused legacy tests and matching Test262 language directories, including abrupt completion, iterator closing, derived constructors, eval scope, mapped arguments, and single-evaluation cases.

## Definition of done

- Every covered construct compiles directly from OXC and executes without a legacy callback.
- Environment identity, declaration ordering, errors, and effects match the oracle.
- Recursive and suspended paths use the shared activation model.

## Performance evidence

Report frame/environment allocation and Richards/DeltaBlue regressions; correctness owns completion.

## Implementation evidence

The next specializer now lowers base-class declarations and expressions into
the shared constructor/closure, prototype, method-call, and `new` operations.
Instance and static methods are covered by residual execution regressions;
simple static fields now initialize after all class methods are installed,
including the specified `undefined` value for declarations without an
initializer. Simple instance fields now run in constructor activation before
the user body (including implicit default constructors), preserving source
order and the `undefined` default. Heritage now links both constructor and
instance prototype chains through the canonical prototype mutation path.
Explicit `super()` constructors and instance/static `super.method()` (including
computed-key) calls now
capture the evaluated base through the shared activation and call paths;
implicit derived constructors now forward their rest argument vector before
field initialization. Class getters and setters now lower through canonical
descriptor installation while preserving the original receiver; private
elements remain pending. Computed
fields and method keys now use canonical key-expression and indexed-property
paths.

Function declarations, function expressions, classes, and arrows now lower
simple default parameter initializers into an `undefined` guard at function
entry. The regression suite verifies lazy evaluation, explicit arguments, and
arrow defaults. Rest parameters now materialize trailing call arguments as a
fresh array before binding, including function, arrow, and class-method forms.
Calls containing array spreads now materialize their argument vector through
the array `push`/`apply` authorities before invoking `Function.prototype.apply`;
mixed and multi-spread lists preserve left-to-right evaluation and method
receivers, including optional-call nullish short-circuiting. Spread operands
now expand through `Array.from` and the shared iterator protocol, including
custom `Symbol.iterator` sources; abrupt `Array.from` completion closes the
acquired iterator and malformed iterator records are rejected at the shared
protocol boundary. Constructor spread shares the
same materialized vector through `Reflect.construct` and the VM constructor
authority. Call, method, and constructor argument vectors now use an inline
fast path with an out-of-line overflow buffer when needed; the old
eight-argument compiler cap is no longer a semantic limit.
Variable declarations now support simple object and array binding patterns,
with one evaluated initializer feeding field/index loads and local-slot stores;
defaulted binding elements now select their initializer only for `undefined`.
Object binding patterns also evaluate computed and numeric property keys through
the indexed-property authority before recursively binding the selected value.
Destructured formal parameters now bind through the same pattern path for
functions, methods, and arrows, including nested defaults. Rest elements
in array binding patterns now use the shared array slice path; object rest
now copies unexcluded enumerable own properties through the Object.keys and
indexed-property authorities.
Array `for...of` statements now lower directly to the residual loop/activation
operations with hidden local slots for the source and index, preserving state
across block-body temporary release and supporting ordinary `break`/`continue`
control edges. Identifier, member, and destructuring assignment targets now reuse the
shared assignment lowering. Built-in array, string, Map, and Set sources now
lower through heap-backed iterator cells and `.next()` result records; custom
`Symbol.iterator` dispatch now shares the residual call path, while
`for await...of` remains pending. `try/finally` and
`try/catch/finally` now run their finalizers on normal and thrown completions
and rethrow the original value; return completion routing also runs through
the finalizer, and loop break/continue edges now route through derived
finalizer paths as well.
Labeled statements now carry named control targets so `break label` can exit a
labeled block, loop, or switch through the same patched control edges. Labeled
`continue` now targets directly labeled loop controls. `break` exits through
one VM-owned iterator-close operation that invokes a present `return()` method;
return/throw completion closing and async iterator paths remain pending.
Catch clauses now accept object, array, and defaulted binding patterns by
capturing the thrown value into a hidden handler slot and reusing the shared
destructuring binder.
Static class blocks now compile as immediate closures invoked with the class as
`this`, interleaved with static-field initialization in source order.
Numeric and other expression-valued object-literal keys now lower through the
same indexed-property path instead of being rejected by the OXC specializer.
Destructuring assignment targets now reuse the declaration binder's recursive
value flow for array/object targets, nested defaults, computed keys, array
rest, and object rest; the subset suite covers the result and exclusion
semantics.
Class accessor regressions cover instance getter/setter receiver behavior and
static getters.
