- `test-blocklist-fast-api.js` if it turns out to test a V8 "fast API"
  binding mechanism that has no equivalent in quench-node's engine — note
  the finding rather than forcing an implementation

  asserts Node's V8 startup-snapshot/native-module bootstrap sequence, for

  exposes the public `process.moduleLoadList` shape, but does not fabricate
  Node's internal inventory; the fixture remains a documented follow-up.
