# 01: Freeze baselines and rewrite inputs

## Outcome

Create reproducible correctness and performance baselines before deleting any legacy mechanism.

## Current gap

The pinned submodules are not initialized in this worktree, the runtime suite currently has one Atomics failure and one ignored timing probe, and no single record ties Quench and `../v2` results to exact revisions.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

1. Verify the Quench and `../v2` commits recorded in the index and initialize the pinned Test262, Node, Wasm, and V8-v7 submodules.
2. Generate deterministic inventories for Test262 tests, Wasm directives, and tracked `tests/node-compat` fixtures; store raw outputs under `target/rewrite-baseline/`.
3. Force the legacy interpreter-only path and record workspace/runtime, Node smoke, Test262 smoke, Wasm smoke, and all tracked compatibility outcomes without changing classifications.
4. Build the pinned v2 source and record its 63-test result plus paired Score/RSS samples for Richards, DeltaBlue, Crypto, and Splay.

## Verification

Re-run every inventory command and confirm identical counts and revisions. Preserve the known Atomics failure as an explicit cleanup input rather than normalizing it away.

## Definition of done

- Every baseline artifact names source commit, submodule revisions, command, binary, toolchain, host, and environment.
- All required suites discover nonzero work.
- The legacy interpreter and v2 reference can be rebuilt from the recorded inputs.

## Performance evidence

Record raw v2 and interpreter-only Quench measurements; this task makes no parity claim.
