# 27: Cut over to the single VM and delete the legacy runtime

## Result

Completed the production cutover. `quench-runtime` is the sole JavaScript and
WebAssembly VM package and owns the only `Vm` implementation. `quench-node`,
`quench-test262`, and `quench-wasm` use that runtime; `NodeHost` registers only
the shared Node adapters. Removed the legacy VM package, execution adapters,
standalone executors, and audited unregistered polyfill fragments. Compatibility
helpers such as `url_legacy` and `legacy_try` remain only for their named API
and WAST normalization behavior; they do not execute JavaScript.

The coordinated OXC parser, AST, semantic, span, syntax, and allocator
dependencies use the exact 0.153.0 release. The vendored parser patches retain
only Quench's stack-budget integration and Annex B parse option. Separately
versioned crates such as `oxc_resolver` retain their own release version.

Task 86 completed final production qualification after the cleanup. Its tracked
[evidence](evidence/task86-stagea-final-2026-10-08.json) records the one-VM and
OXC audits, suite inputs, binaries, full reports, and the Node-arbitrated raw
Test262 waiver. Stage A is closed; the queue advances to Stage B Task 62.
