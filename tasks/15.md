## Scope and implementation sequence

Port Number, BigInt, Math, parsing/formatting, Date/time zones, all current ICU-backed Intl services, and Temporal objects/rounding/calendars/durations. Keep ICU and arbitrary-precision libraries behind explicit conversions and canonical object slots. Intl, Temporal, Date, and numeric formatting each retain one surviving algorithm authority. Migrate missing behavior from legacy without retaining a second implementation or waiting for deferred shared-crate or watermark proposals. This task closes its affected Test262 slices as part of Stage A.

## Verification

Run Number/BigInt/Math/Date/Intl/Temporal Test262 families across NaN, infinities, signed zero, huge integers, locale options, DST boundaries, calendar transitions, rounding modes, and accessor effect order.

## Definition of done

- Numeric results and formatting match Test262 and Node.
- Locale/time-zone data dependencies are reproducible.
- Temporal identity and slots use the new heap exclusively.
