# 26: Match v2 Score and RSS

## Outcome

Reach the agreed Apple M4/macOS throughput and memory gate against the pinned v2 interpreter.

## Current gap

Full semantics and hostability add representation and dispatch costs that have not been measured against the clean reference implementation.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

Build production standalone binaries for pinned v2 and the next Quench core with matched toolchain/profile/PGO policy. Run odd rotating paired tournaments for Richards, DeltaBlue, Crypto, and Splay. Optimize only general v2-style mechanisms—binding-time facts, residual rewrites, dispatch, shapes/caches, allocation/GC, layout, and AOT compiler policy—with exact fallback and held-out semantic controls.

## Verification

Use at least 11 complete pairs per comparison. Reject runs with missing samples, more than 5% control drift, mismatched sources/binaries/page size, or invalid benchmark results. Run task 24's focused safety controls after every retained mechanism change and the full gate before completion.

## Definition of done

- For each workload, Quench median Score is at least the pinned v2 median.
- For each workload, Quench median maximum RSS is no greater than the pinned v2 median.
- Reports include ordered raw samples and 95% paired intervals; no benchmark-shaped behavior exists.

## Performance evidence

The matched reports are this task's primary deliverable. Also report startup, specialization time, residual bytes, GC, and regression analysis.
