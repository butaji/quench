# 085: Prune warning-backed dead code

After the structural cleanups, make the active runtime and Node library targets
warning-clean. The current `cargo check -p quench-node --lib` emits roughly 277
warnings, including dead functions, variants, imports, and unreachable arms.

## Plan

- Capture a baseline warning list by target and subsystem.
- Delete genuinely unreachable functions/variants/imports; put experimental or
  test-only paths behind precise cfg/features.
- Avoid blanket `allow(dead_code)` and preserve public compatibility deliberately.
- Run focused subsystem tests, then the full runtime/Node/oracle matrix.

## Acceptance

The default active targets have no unexplained warnings, removed code has no
reachable callers, and semantic, host-effect, and exit-status behavior remains
unchanged.
