## Context

Deegen (arXiv:2411.11469) is a two-tier design: interpreter + baseline JIT +
tier-switching (tier-up, OSR-entry) between exactly those two tiers — no
optimizing JIT, no deoptimization (see `docs/deegen-alignment.md`). An
inventory pass found the working tree already contains most of what's needed
for tier-switching: `machine.rs` has `TierState`/`enter_invocation`/
`retire_at` (hotness-threshold tier-up, matching the paper's retired-bytecode
counting design) and `is_osr_candidate`/`is_osr_entry` (back-edge OSR
admission). None of it is committed; it hasn't been run through the
correctness gate or the neutral micro-corpus since landing.

## Scope

## Deliverables
- Reconcile the working tree into a clean, buildable state
- Run and pass: `cargo test -p quench-runtime --lib --no-default-features`,
  `cargo test -p quench-runtime --lib --features execution-trace`,
  `cargo check -p quench-node`
- Run the neutral micro-corpus (`node quench-bench/micros/verify.mjs --engine
  target/debug/quench-node --oracle node --from 1 --to 100 --runs 3

  vs. the last recorded snapshot in `docs/architecture-evidence.md`

  state, OSR admission, expanded stencil regions — check the real diff rather
  than assuming)

## Validation

Run these in order; every one must pass before committing:

1. `cargo fmt --all -- --check` — no formatting drift
2. `cargo test -p quench-runtime --lib --no-default-features` — full pass, 0 failures
3. `cargo test -p quench-runtime --lib --features execution-trace` — full pass, 0 failures
4. `cargo check -p quench-node` — clean
5. `node quench-bench/micros/verify.mjs --engine target/debug/quench-node --oracle node --from 1 --to 100 --runs 3 --timeout-ms 30000 --out target/micro-neutral-evidence-3run.json` — must report **100/100** exact matches
6. Compare the run's aggregate wall-time/RSS/instruction/cycle ratios against the last snapshot in `docs/architecture-evidence.md` (0.964x/0.428x/1.135x/1.002x, index 156.04) — no metric regresses by more than measurement noise (~2-3%); if one does, find the cause before committing, don't average it away
7. `git status` after commit is clean (no leftover unstaged hunks)

**Fail condition**: any test failure, any oracle mismatch, or a regression in step 6 blocks the commit. Do not drop, skip, or `#[ignore]` a failing test to get to green — fix the cause or report it instead of committing.
