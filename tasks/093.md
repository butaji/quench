# 093: Unify property and call inline caches

## Outcome

Provide reusable guarded property/call specialization across interpreter and JIT.

## Current gap

Quickening and specialized property/call plans still repeat receiver, callee,
layout and continuation facts. Their bounded physical storage now shares the
same generic key/state table for shape and weak-callable entries; the remaining
work is to unify the semantic guard facts and invalidation/commit protocol. A
site-backed named write and own-data named method call now treat that generic
shape/state table as the sole own-slot authority; the packed layout/slot cache
remains only for legacy callers and inherited/virtual property states where no
own-shape proof applies.

## Dependencies

See this task's `depends_on` in [index.json](index.json); status and ordering live there.

## Scope and implementation sequence

1. Declare cache states and dependencies once; derive generated fast paths and shared miss handling.

2. Implement monomorphic/polymorphic hits, megamorphic fallback and invalidation on callee/descriptor/prototype/backing mutation.

3. Share proven guards across effect-free regions; kill or revalidate facts after effects.

4. Migrate independent call/property selectors to the shared cache facts and exact commit protocol.

## Verification

`cargo test -p quench-runtime`; reserved property/prototype/call micros; own-data
named method-site install/hit/invalidation controls; adversarial receiver
changes, delete/re-add, nonwritable strict stores, accessors, proxy reentry and
stale dependency tests.

Apply the shared [completion checks](README.md), including named baseline failures
and independent semantic controls. Record commands and artifact identity.

## Definition of done

- Stable ordinary property/call sites use generated paths with correct invalidation and shared semantics.
- Churn does not repeatedly compile or retain obsolete entries without justified policy.
- Every miss and mutation path preserves receiver identity, ownership, results and exactly-once effects.

## Performance evidence

Require matched affected-workload evidence with V8-v7 as the primary M4 signal and
matched Bun/JSC/Node comparator runs where the protocol supports them; report
cache bytes, miss causes and warmup cost.
