## Dependencies

3. Verify bootstrap text/order before and after and update source links.

## Verification

`cargo test -p quench-node`; `cargo run -p quench-node-test --bin run-compat`; Node-oracle bootstrap/global/descriptor controls. Compare materialized bootstrap bytes and order.

Apply the shared [completion checks](README.md), including named baseline failures
and independent semantic controls. Record commands and artifact identity.

- Bootstrap bytes/order and observable globals/host behavior are unchanged.
