# 21: Adapt Node core to the capability ABI

## Outcome

Run core Node-compatible behavior on the next runtime through explicit capabilities and persistent roots.

## Current gap

`quench-node` directly imports hundreds of legacy runtime operations and value variants, which cannot survive the new heap or narrow host boundary.

The legacy `quench-node` dispatch layer (`dispatch.rs`'s ~1,100-arm match, fed
by ~20 same-purpose `js_runtime_dispatch_*` files split across
`misc_a`-`misc_e`, `crypto_a`-`crypto_c`, `buffer`, `fs`, `url`, `tmpdir`, and
more) is a decision tree wearing a directory structure: many files, each
holding another chunk of the same match. The new capability ABI must not
reproduce this shape. "Capability registration is data-derived and
duplicate-safe" below means one capability table (name/ID to typed handler
plus argument/return shape), the same table-over-branches pattern used
elsewhere in the rewrite (`compile/rewrite.rs`'s `fusion_recipes!`, the
typed-array install table), not a large match split across many files that
only look modular by filename.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

Generate stable capability IDs from the Node registry and adapt globals, process, console, Buffer, path, URL, util, filesystem, CJS/ESM loading, errors, and bootstrap behavior. Replace retained `Value` objects with `RootId`s and explicit release. Keep Node behavior in `quench-node`; expose no heap cell or object storage to the host.

## Verification

Compare focused fixtures with local Node for values, descriptors, identity, key ordering, exceptions, argv/execArgv, exit status, output, filesystem effects, module caching, and realm behavior. Stress GC during every host callback class.

## Definition of done

- Core fixtures run through `quench-node-next` without legacy calls.
- Capability registration is data-derived and duplicate-safe.
- Host-held callbacks/objects remain valid only through explicit roots.

Report bootstrap time/RSS and host-call/root-table counts.
