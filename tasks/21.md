- The existing host remains the sole owner of Node semantics.

- No new host capability or discretionary architecture blocks closure.

## Entry contract

The development CLI selects OXC's Module goal for `.mjs` and package-scoped
`.js` with `type: module`; CommonJS entries execute through the standard
wrapper. Eval installs CommonJS globals in the active shared realm. Node owns
format selection and the named unsettled-top-level-await exit status 13; the
runtime projects its existing module evaluation state after jobs drain. Shared
host re-entry preserves roots and does not inherit caller lexical bindings.

Upstream fixtures must execute in their declared context. A nested checkout can
inherit this repository's `type: module`, which changes ordinary `.js`
invocation. The loader qualification isolates byte-identical CommonJS fixtures
and the real upstream helper tree outside that application package, recording
source hashes. It also records direct repository invocations separately; neither
invocation mode edits suite inputs or constitutes a complete implemented-case
gate.
