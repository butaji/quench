# 060: Request-scoped allocation proposal

Deferred pending a concrete host/framework use case and explicit user approval
of the ownership/API contract. It is not a stencil infrastructure prerequisite.

Do not infer object lifetime from an HTTP request ending: closures, globals,
Promises and timers can retain references. No speculative request-arena API,
automatic request detection or unsafe application non-escape promise.

If reopened, prove safe escape handling, unchanged ordinary behavior and
bounded lifetime with differential and long-running tests before claiming value.
Prefer existing allocation mechanisms unless new evidence justifies a change.
