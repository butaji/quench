# 12: Port object, Reflect, Proxy, and Symbol semantics

## Outcome

Complete the ECMAScript meta-object protocol on the canonical object model.

## Current gap

Shapes and ordinary internal methods do not yet cover Proxy invariants, Reflect, Symbols, private slots, exotic descriptors, or all property-ordering rules.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

Port Object and Function prototype behavior, descriptors, integrity levels, prototype mutation, Symbols and registries, private slots, bound functions, Proxy traps/invariants/revocation, Reflect, module/global exotics needed by shared operations, and exact own-key ordering. Route every fast path through proven guards on these operations.

## Verification

Run object/proxy/reflect/symbol/private-field Test262 families and adversarial descriptor, prototype, trap re-entry, duplicate-key, revoked-proxy, and cache-invalidation controls.

## Definition of done

- All object internal methods have ordinary and exotic dispatch from one contract.
- Proxy invariants and effect order match Test262/Node.
- Symbols and private names never collapse into string keys.

## Performance evidence

Report property/cache counters and object-heavy workload changes.

## Implementation evidence

The next specializer now lowers object destructuring rest by enumerating own
keys, skipping statically bound properties, and copying the remaining values
through the shared object/index operations. Proxy and descriptor-complete
rest semantics remain on the conformance path.

`Symbol.for` and `Symbol.keyFor` now use a VM-owned registry with heap roots,
stable identity, and explicit errors for non-symbol `keyFor` arguments. The
subset suite covers registry identity and local-symbol distinction; property
keys and the remaining well-known symbols still require the object-model
completion.
The primitive `typeof` path also distinguishes heap-backed `symbol` and
`bigint` values from ordinary objects.
Object literals now lower computed identifier and primitive-literal keys through
the same indexed-property authority, reusing the canonical expression compiler;
spread properties now route through `Object.assign` in source order. Proxy,
descriptor, and symbol-key edge cases remain on the conformance path.
`Object.keys` now derives own-key order from the canonical shape table and
returns a runtime array, keeping key names single-sourced from interned atoms.
`Object.create` now allocates an ordinary shape-backed object with an explicit
prototype pointer, exercising inherited lookup while keeping own-key shape
ordering independent.
`Object.assign` now snapshots each source shape in argument order and routes
writes through the normal property transition/cache invalidation path.

Object integrity levels now track extensibility and descriptor flags in the
same VM-owned metadata: `preventExtensions`, `seal`, and `freeze` block new or
non-writable writes, while the corresponding `is*` predicates report ordinary
objects and primitive inputs correctly. Cached field writes perform the same
descriptor guard as generic writes; focused subset coverage exercises sealed
and frozen mutation failures.
`Reflect.preventExtensions` and `Reflect.isExtensible` now share the same
state and enforce the object-target TypeError boundary.
Prototype mutation now shares the non-extensible invariant: `Object` throws
and `Reflect` returns `false` when a different prototype is requested.
`Object.getPrototypeOf` and `Object.setPrototypeOf` now read and mutate the
ordinary object's canonical prototype slot with object/null validation.
Basic `Reflect.get`, `set`, `ownKeys`, and prototype operations forward to the
same methods, preserving one property/prototype authority across both APIs.
`Object.hasOwn` now converts its key through the canonical string authority and
checks only direct shape slots, while rejecting nullish targets.
`Object.getOwnPropertyNames` now reuses the same shape-derived own-name array
and ordering as `Object.keys`.
`Object.fromEntries` now builds ordinary shape-backed objects from array entry
pairs, coercing keys through the shared string authority and preserving the
last-write value.
`Object.is` now uses an explicit SameValue authority: `NaN` compares equal,
signed zero remains distinct, primitive strings and BigInts compare by value,
and heap objects retain identity semantics.
`Object.values` and `Object.entries` now derive values and key/value pair arrays
from the same shape slots and insertion order as `Object.keys`.
`Object.prototype.hasOwnProperty` now uses the call receiver and the same direct
shape-slot check as `Object.hasOwn`.
`Object.prototype.propertyIsEnumerable` now shares that own-slot authority for
ordinary properties in the staged descriptor model.
`Object.prototype.isPrototypeOf` now walks the same canonical prototype links
used by object creation and mutation.
`Object.getOwnPropertyDescriptor` and `Reflect.getOwnPropertyDescriptor` now
derive ordinary data descriptors from canonical shape slots; absent properties
return `undefined`.
`Object.getOwnPropertyDescriptors` now materializes the complete ordered
descriptor map from that same shape authority.
`Object.defineProperty` and `Reflect.defineProperty` now track writable,
enumerable, and configurable flags in a VM-owned attribute table, filter object
enumeration accordingly, and reject incompatible non-configurable rewrites.
Own-key views now apply ECMAScript integer-index ordering before insertion-order
string keys, shared by `Object.keys`, `Object.values`, `Object.entries`,
`Object.assign`, and `Reflect.ownKeys`.
The same object coercion path now boxes primitive strings with UTF-16 indexed
own properties for object views, assignment, and both `hasOwn` method forms.
