## Scope and implementation sequence

Port Object and Function prototype behavior, descriptors, integrity levels, prototype mutation, Symbols and registries, private slots, bound functions, Proxy traps/invariants/revocation, Reflect, module/global exotics needed by shared operations, and exact own-key ordering. Route every fast path through proven guards on these operations.

## Definition of done

- All object internal methods have ordinary and exotic dispatch from one contract.
- Proxy invariants and effect order match Test262/Node.
- Symbols and private names never collapse into string keys.

## Implementation evidence

The next specializer now lowers object destructuring rest by enumerating own
keys, skipping statically bound properties, and copying the remaining values
through the shared object/index operations. Proxy and descriptor-complete
rest semantics remain on the conformance path.

`Symbol.for` and `Symbol.keyFor` now use a VM-owned registry with heap roots,
stable identity, and explicit errors for non-symbol `keyFor` arguments. The
subset suite covers registry identity and local-symbol distinction; property
keys and the remaining well-known symbols still require the object-model
completion.
The primitive `typeof` path also distinguishes heap-backed `symbol` and
`bigint` values from ordinary objects.
Object literals now lower computed identifier and primitive-literal keys through
the same indexed-property authority, reusing the canonical expression compiler;
spread properties now route through `Object.assign` in source order. Proxy,
descriptor, and symbol-key edge cases remain on the conformance path.
`Object.keys` now derives own-key order from the canonical shape table and
returns a runtime array, keeping key names single-sourced from interned atoms.
`Object.create` now allocates an ordinary shape-backed object with an explicit
prototype pointer, exercising inherited lookup while keeping own-key shape
ordering independent.
`Object.assign` now snapshots each source shape in argument order and routes
writes through the normal property transition/cache invalidation path.
Proxy sources now use the shared `ownKeys`/descriptor authorities and read
each enumerable value through the source receiver, preserving symbol keys and
proxy `get` effects. `Object.values` and `Object.entries` use the same path for
string-keyed proxy views.

Object integrity levels now track extensibility and descriptor flags in the
same VM-owned metadata: `preventExtensions`, `seal`, and `freeze` block new or
non-writable writes, while the corresponding `is*` predicates report ordinary
objects and primitive inputs correctly. Cached field writes perform the same
descriptor guard as generic writes; focused subset coverage exercises sealed
and frozen mutation failures.
`Reflect.preventExtensions` and `Reflect.isExtensible` now share the same
state and enforce the object-target TypeError boundary.
Prototype mutation now shares the non-extensible invariant: `Object` throws
and `Reflect` returns `false` when a different prototype is requested.
Dense and sparse array index writes now pass through the same seal/freeze
guard instead of bypassing integrity metadata in the indexed fast path.
`Object.getPrototypeOf` and `Object.setPrototypeOf` now read and mutate the
ordinary object's canonical prototype slot with object/null validation.
Basic `Reflect.get`, `set`, `ownKeys`, and prototype operations forward to the
same methods, preserving one property/prototype authority across both APIs.
`Object.hasOwn` now converts its key through the canonical string authority and
checks only direct shape slots, while rejecting nullish targets.
`Object.getOwnPropertyNames` now reuses the same shape-derived own-name array
and ordering as `Object.keys`.
`Object.fromEntries` now builds ordinary shape-backed objects from array entry
pairs, coercing keys through the shared string authority and preserving the
last-write value.
`Object.is` now uses an explicit SameValue authority: `NaN` compares equal,
signed zero remains distinct, primitive strings and BigInts compare by value,
and heap objects retain identity semantics.
`Object.values` and `Object.entries` now derive values and key/value pair arrays
from the same shape slots and insertion order as `Object.keys`.
`Object.prototype.hasOwnProperty` now uses the call receiver and the same direct
shape-slot check as `Object.hasOwn`.
`Object.prototype.propertyIsEnumerable` now shares that own-slot authority for
ordinary properties in the staged descriptor model.
`Object.prototype.isPrototypeOf` now walks the same canonical prototype links
used by object creation and mutation.
`Object.getOwnPropertyDescriptor` and `Reflect.getOwnPropertyDescriptor` now
derive ordinary data descriptors from canonical shape slots; absent properties
return `undefined`.
Named and symbol deletion now uses a tombstone in the canonical property arena,
so shape/cache identities remain stable while own-key views, descriptors,
enumeration, GC traversal, and later redefinition agree that the property is
absent. `Reflect.deleteProperty`, Proxy `deleteProperty` traps, and member
`delete` expressions share this authority and enforce non-configurable target
invariants. Dense array slots use the same tombstone value, preserving length
while indexed reads, iterators, JSON, and redefinition observe a hole.
Array index own-key views now derive integer keys from dense and sparse storage,
omitting tombstoned holes while retaining numeric ordering.
Indexed array descriptors now use the VM descriptor table for reflection,
definition, and seal/freeze checks, including non-enumerable and read-only
index transitions. Array index accessor descriptors use that same authority for
getter/setter reads and writes, descriptor reflection, deletion, and own-key
presence. `Object.values` and `Object.entries` read numeric keys through
indexed access, so holes and descriptor-filtered indices stay aligned with
`Object.keys`.
`Object.getOwnPropertyDescriptors` now materializes the complete ordered
descriptor map from that same shape authority.
`Object.defineProperty` and `Reflect.defineProperty` now track writable,
enumerable, and configurable flags in a VM-owned attribute table, filter object
enumeration accordingly, and reject incompatible non-configurable rewrites.
Accessor descriptors now use that same attribute authority for getter/setter
identity; ordinary reads invoke inherited getters and field writes invoke the
receiver's inherited setter, including through the optimized and generic
paths. The packet accessor differential fixture and a focused runtime test
cover descriptor reflection, receiver identity, and setter effects.
Accessor getter/setter handles are included in the VM's GC root set, and
`Object.assign`, `Reflect.set`, and computed index writes route through the
same accessor-aware write operation.
Writes that would shadow an inherited non-writable data property are rejected
by the same prototype walk before any shape transition.
Own-key views now apply ECMAScript integer-index ordering before insertion-order
string keys, shared by `Object.keys`, `Object.values`, `Object.entries`,
`Object.assign`, and `Reflect.ownKeys`.
The same object coercion path now boxes primitive strings with UTF-16 indexed
own properties for object views, assignment, and both `hasOwn` method forms.
Array mutators now share the integrity boundary too: sealed arrays reject
length-changing `push`/`pop`/`shift`/`unshift`/`splice` operations while still
allowing writes to existing indices, and frozen arrays reject mutating methods
including `fill`, `copyWithin`, `reverse`, and `sort`.

The canonical heap now has a GC-traced `Proxy` cell. `new Proxy(target,
handler)` validates both object operands and routes optimized and generic named
property reads/writes through the handler's `get`/`set` traps, passing the
target, canonical string key, and receiver; absent traps forward to the target.
Default object key/name/value/entry views, own descriptors, and prototype reads
also unwrap through the same target authority. The focused subset covers trap
identity, target mutation, revocation, and ordered `ownKeys` reflection. The
`ownKeys` trap result is normalized once for `Reflect.ownKeys`, `Object.keys`,
`Object.getOwnPropertyNames`, and `Object.getOwnPropertySymbols`, rejecting
primitive and duplicate keys. It now enforces required non-configurable target
keys and exact key coverage for non-extensible targets. Descriptor trap
dispatch, callable/constructable proxies, and the remaining target-invariant
rules remain on the conformance path.
`getOwnPropertyDescriptor` traps now dispatch for Object/Reflect descriptor
reflection, preserve symbol keys, and reject primitive trap results.
They also enforce the required non-configurable and non-extensible target
descriptor invariants. `Object.getOwnPropertyDescriptors` now consumes the
same proxy key and descriptor authorities instead of unwrapping the target.
`defineProperty` traps now receive the canonical target, property key, and
descriptor and control Object/Reflect definition success. Successful traps
are checked against the target's extensibility, descriptor kind, and
non-configurable/non-writable/accessor invariants before returning; symbol
keys use the same identity-preserving path. `getPrototypeOf` and
`setPrototypeOf` traps now route Object/Reflect prototype operations through
the same proxy handler and boolean-result boundary. `preventExtensions` traps
now route Object/Reflect integrity operations and preserve the Object-throw vs
Reflect-false distinction. `isExtensible` traps now drive Object/Reflect
integrity queries through the same boolean result path and enforce agreement
with the target's current extensibility. Prototype and `preventExtensions`
traps likewise reject results that violate non-extensible-target invariants.
Proxy `seal`/`freeze` now forward through prevent-extension, key, descriptor,
and define-property authorities while preserving target writable state;
`isSealed`/`isFrozen` inspect the target integrity state.

Callable and
constructable proxy targets now route through `apply` and `construct` traps
(or exact target fallback), preserving receiver identity, argument-list
materialization, and object-result validation.

Symbol-keyed properties now use an ordered VM-owned side table rather than
string coercion. Indexed reads/writes, `Object.hasOwn`, define/reflect
descriptors, `Object.getOwnPropertySymbols`, `Reflect.ownKeys`, and enumerable
`Object.assign` copies preserve symbol identity and insertion order; GC traces
both symbol keys and values. Proxy `get`/`set` forwarding now passes symbol keys
without coercion. Standard well-known symbols are allocated once per VM
initialization and installed on `Symbol` with stable identity.
Symbol descriptions and primitive `toString`/`valueOf` methods also use the
same symbol cell identity. Symbol writes now honor descriptor writability, and
seal/freeze plus their predicates include symbol-keyed descriptors.

Array `length` now participates in the canonical own-descriptor path with its
live value and non-enumerable, non-configurable attributes; a focused runtime
regression matches the local Node oracle.
Array own-key views now include `length` for `Object.getOwnPropertyNames` and
`Reflect.ownKeys` while filtering it from `Object.keys` through the same
descriptor attributes.

The `instanceof` abstract operation now throws when `@@hasInstance` is absent
or nullish and the right-hand side is not callable, while preserving the
callable-method path and callable-proxy recognition. The existing stage-10
`instanceof` selection passes 57/57 with positive 30,000 ms per-case timeouts
