# 04: Import the pinned v2 runtime snapshot

## Outcome

Create an in-repository `quench-runtime-next` crate that is a reviewable source copy of the pinned v2 VM.

## Current gap

Quench's existing private core is not the interpreter currently implemented by `../v2`, and production builds may not depend on a sibling checkout.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

1. Copy `../v2/crates/vm` at the indexed commit, preserving its module layout, bytecode, compiler, heap, host, profiling, tests, and implementation order.
2. Rename only crate/package symbols and environment prefixes needed to coexist with the legacy runtime; record source provenance in the crate.
3. Add the temporary workspace member and exact OXC 0.150 dependencies without wiring it into production binaries.
4. Keep v2's interpreter-only integrity rules and reject benchmark/name/body-specific specialization.

## Verification

Require the copied crate to pass the same 35 unit, 27 subset, and one module-structure test as the pinned source. Diff imported production code against the reference and explain every non-rename difference.

## Definition of done

- The next crate builds without `../v2` present.
- All 63 reference tests pass unchanged in meaning.
- Production `quench-node` still uses only the legacy interpreter.

## Performance evidence

Confirm the copied standalone VM reproduces the reference measurements within ordinary run variance; this is provenance evidence, not the final parity gate.
