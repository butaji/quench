# 007: Generate guarded quickening and inline-cache state

- **Theme:** deegen_codegen
- **Executor:** codex
- **Depends on:** 006

## Scope
- crates/quench-runtime/src/vm
- crates/quench-runtime/src/shape_cache.rs

## Deliverables
- Generate bounded cache states, guard predicates, miss transitions, and fallback edges from facts
- Provide a catalog-backed quickening site whose eligibility and certainty use the vm_op facts
- Share semantic cache mechanisms while specializing physical execution
- Keep heap references compact and account for cache/static-data cost

## Acceptance
- Every cache miss reaches ordinary semantics without semantic drift
- Cache growth is bounded and cache state is disposable

## Non-goals
- A tracing or optimizing JIT
