## Scope and verification

Use the existing manifest as the only fixture selection authority and the
framework package lock as the scenario dependency authority. Verify exact
values, descriptors, identities, ordering, errors, exit status, raw
stdout/stderr and required host effects against local Node. A failure reopens
the owning implementation task; it never removes the case or changes its
expected result.

During changes, run only affected fixtures and scenarios. At this task's
qualification, run the full framework profile and all three package scenarios
on one source/build snapshot. Do not execute or classify the broader
`node-compat-inventory.json` as a Stage A gate.

## Definition of done

- Every manifest-selected `framework-core` fixture passes without skips,
  timeouts, crashes or unclassified results.
- Express, Koa and Fastify each pass the pinned scenario and match local Node
  on exit status and raw stdout/stderr.
- The recorded evidence binds the manifest, package inputs, source snapshot,
  binaries and outputs.
