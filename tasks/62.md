# 62: Add no-JIT reference engines to the V8-v7 runner

## Plan scope

Required Stage B measurement tooling after task 86 verifies Stage A. Task 61
needs these matched reference-engine runs to qualify Score and maximum RSS.
Use affected-stage checks plus compare-runs during changes. The current
dependencies in [index.json](index.json) supersede older prerequisite claims.

## Outcome

The Rust V8-v7 runner (`quench-bench`) measures Quench against QuickJS, Bun
with the JSC JIT disabled, and Node with `--jitless`, on all eight fixtures,
with per-fixture Score and maximum RSS. Each run records proof that the
reference engine's JIT was off.

## Current gap

The runner accepts `--quench`, `--node`, and `--bun`, but it runs Node and Bun
with their JITs enabled and has no QuickJS engine
([V8-v7 commands](../docs/v8_v7.md)). Task 61's gate therefore cannot be
measured.

## Dependencies

See this task's `depends_on` in [index.json](index.json). This task is
measurement tooling only, scheduled in Stage B after Stage A verification.

## Scope and implementation sequence

1. Add a `--qjs <path>` engine that uses the same materialized suite wrapper as
   the other engines.
2. Add no-JIT modes for Node (`--jitless`) and Bun (JSC `useJIT=false`, set
   through Bun's JSC option environment). Record the engine version and the
   effective flags or options in each sample.
3. Verify that each mode is really interpreter-only, with an engine-reported
   option dump or an equivalent check. Mark a run invalid when the check fails
   or cannot run.
4. Report per-fixture maximum RSS for every engine through the existing
   external accounting.
5. Update [`docs/v8_v7.md`](../docs/v8_v7.md) with the commands.

## Verification

Use task 61's first matched baseline campaign to verify all eight fixtures
for all four engines, with provenance and JIT-off evidence in every sample.
Do not run a separate duplicate baseline campaign for this tooling task.
Confirm that a deliberately JIT-enabled run is rejected as invalid.

## Definition of done

- The runner measures Quench, QuickJS, Bun/JSC without JIT, and Node/V8
  `--jitless` on all eight fixtures.
- JIT-off evidence is part of each sample, and runs without it are invalid.
- The docs describe the commands.

## Performance evidence

Record the first four-engine baseline under `target/`. This is measurement
only.
