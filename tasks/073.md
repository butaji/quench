## Dependency-ordered scope

### A. Trustworthy evidence and shared static metadata

Apply [observability contracts](../docs/observability-architecture.md):
generated event IDs/units/populations; immutable code attribution outside hot
increments; bounded detail with explicit omissions and sampling policy.
Audit lifecycle constructor/clone/drop populations before deriving live gauges.
Count physical headers/backings, resize, Rc aliases and semantic creation distinctly.
Measure profiler perturbation; never rank diagnostic hashing as production cost.
Freeze function frame requirements from canonical operands and same-frame fragments,
not repeated call-time traversal. Preserve callee/frame boundaries and sentinel roles.

### B. Shared activations and heap identity

Follow [activation architecture](../docs/activation-architecture.md):
compare existing pooling with bounded slot storage and selective captures.
Share frame/exit/root/suspension contracts; keep specialized interiors unboxed.
Eliminate dead local state only from use/def, escape and effect facts. Preserve
TDZ, eval, with, mapped arguments, defaults, coercions, calls and throws.
Measure initialization work separately from frame construction and retention.

Follow [heap identity](../docs/heap-identity-architecture.md):
stable identity with mutable backing; distinct shape/kind/length/backing validity;
implicit default attributes and internal descriptor records rather than public
descriptor objects for internal queries. Share ordinary, IC and native mechanisms.
Historical slice/species controls implicate destination construction, not source
construction alone; Crypto stale-representative misses do not prove missing I32.
Validate stale aliases, species/accessors, sparse holes, mapped arguments and
callback/resize boundaries. Reclaim released latest representatives without
manual global reset while live aliases continue to resolve correctly.
Unify immutable layout metadata, not semantically different ID domains: cached
interned layouts and visible-name shape fingerprints must have explicit roles.
Derive dictionary flags/slot counts without repeated property-name scans; select
descriptor keys before decoding unrelated values. Test transitions, metadata
mutation, ordering and hash collisions; preserve reentrancy-safe borrow boundaries.

### C. Ownership, reclamation and code lifetime

Audit actual owning edges rather than recursively counting semantic reachability.
Cover arrays, objects, functions, shared cells/environments, host/native references,
active/suspended frames and escaping closures. Deduplicated traversal must not
erase owning-edge multiplicity. Derive root/edge diagnostics from one contract.
Measure code-store disposal, captures retaining unrelated values, replacement
storage, survival and pauses before selecting collector policy.
Fresh trace-off EarleyBoyer sampling contains cycle/environment-edge traversal;
older frame-dominated samples are not a current exclusion of collector costs.
Require phase-matched collection frequency, visited-edge and temporary-byte
evidence before choosing visitor changes, scheduling or collector migration.
Compare retaining RC with corrected cycle accounting against a scoped collector
migration; no blanket Rc removal, unsafe nursery arithmetic or threshold inflation.
Any moving/generational proposal includes every root/handle/weak-reference/barrier
and safepoint contract, byte costs and migration tests. Task060 remains separate.

### D. Bounded native regions and calls

Use [region composition](../docs/region-composition-architecture.md).
Existing CFG validation, liveness and region contracts are not absent.
Verify their consumers support useful bounded composition and loop residency.
Use effect-scoped facts, backedge-compatible representations, explicit live exits,
fixed-role transfers and planning/code budgets. Cost matches by guards, boxing,
moves, spills and bytes, not longest match or a fixed fusion/template quota.
Compare scalar, composed and fused forms on training and held-out patterns.
Measure baseline-plan construction separately from retained sparse admissions:
temporary per-family vectors, BTreeSet liveness and repeated passes may have cold
cost even when native constructors reject policy. Compare generated single-pass
admission, reusable static CFG facts and deferred native-only work. The slab is
lazy; do not count configured capacity as allocated executable pages.

Extend range proofs only where alias/effect and JS numeric semantics permit.
Do not reassociate floating arithmetic or infer signed I32 from unsigned shifts.
Existing unboxed f64 arrays precede any new element-kind proposal; measure copies,
transitions and access costs first, including -0, NaN, holes and inherited values.
Tiny-call fusion reuses callee/environment/dependency facts and exact this/argument
order. Bound expansion, recursion, guards and code bytes; reconstruct live state.
Pre-shaped allocation/scalar replacement requires initializer order, setter/proto,
escape, identity and exception proofs plus materialization at every required exit.
No benchmark-specific vector/list/node representation.
