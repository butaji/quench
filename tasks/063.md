# 063: Array/collection algorithmic-complexity invariants

- **Theme:** architecture_invariants
- **Executor:** codex
- **Depends on:** none

## Context

Same technique as task 062 (scaling behavior via `execution-trace` counters
or wall-clock ratios, never absolute thresholds), scoped to the array/
`Map`/`Set` subsystem — the next foundation layer that must be proven sound
before task 054 (TypedArray fast-path coverage) or any array-tuning work
proceeds. A complexity bug here (e.g. `Map`/`Set` operations scaling with
the *total number of `Map`/`Set` instances ever created* rather than just
the one instance's entry count — the collection-equivalent of the shape-
count bug 062 tested for) would be exactly the kind of thing that makes
tuning work built on top of it meaningless.

## Scope
- New test module `crates/quench-runtime/src/architecture_invariants.rs`
  (extend the existing module from 062, don't create a parallel one)

## Deliverables — invariants to pin
1. Packed-array indexed access/write cost is independent of array length
   beyond the access itself (accessing index 0 of a 10-element array costs
   the same as index 0 of a 100,000-element array).
2. `Map`/`Set` get/set/delete cost is independent of the total number of
   distinct `Map`/`Set` instances ever created in the runtime (not just
   independent of the one instance's own entry count — the cross-instance
   version of 062's shape-count test).
3. `Map`/`Set`/array iteration cost is proportional to live entry count
   only, not historical add/delete count (the collection-equivalent of
   062's enumeration-vs-mutation-history test, and directly relevant since
   this exact bug class was already found twice for plain objects this
   session).

## Validation

Same bar as 062: state the claimed complexity class per test, validate
each test actually fails against a deliberately-introduced regression
before trusting a pass, `cargo test -p quench-runtime --lib` and
`--features execution-trace` both green.

**Fail condition**: same as 062 — a loose bound that would pass regardless
of the real complexity class defeats the purpose.
