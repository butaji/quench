# 34: Add shape-guarded iterator fast paths

## Outcome

Give `for-of` and spread over dense arrays and typed arrays a fast path that
skips the full iterator protocol (`Symbol.iterator` lookup, `.next()` call,
result-object allocation) when the intrinsic iterator has not been observed to
be overridden, with exact fallback to the full protocol otherwise.

## Current gap

`iterators.rs` implements the generic ECMAScript iterator protocol uniformly.
Iterating a plain dense array pays full protocol cost (method lookup, per-step
result-object allocation) even though the overwhelmingly common case never
overrides `Array.prototype[Symbol.iterator]` or the array's own iterator
property.

## Dependencies

See this task's `depends_on` in [index.json](index.json).

## Scope and implementation sequence

1. Reuse the shape-guard mechanism from task 29 to check, at loop entry, that
   the iterated value's shape and prototype chain still resolve
   `Symbol.iterator` to the original intrinsic array/typed-array iterator
   function, and that no relevant trap (proxy, exotic length) is present.
2. On a passing guard, drive iteration directly over the backing elements
   storage without allocating a per-step `{value, done}` result object or
   invoking the generic `.next()` dispatch.
3. Re-check the guard on any operation within the loop body that could
   invalidate it (e.g. reassigning the prototype's iterator, converting the
   array to a proxy) and fall back to the full protocol from that point,
   preserving spec-exact per-step observable behavior including any
   mid-iteration mutation semantics.
4. Keep the fast path and the generic protocol sharing the same underlying
   element-access primitives used elsewhere (`array_indexed.rs`,
   `typed_array_access.rs`) rather than duplicating element-read logic.

## Verification

Run against task 42's disable-specialization gate and whatever Test262/
Node-compat/Wasm fixture coverage already passes at landing time, as a
regression check independent of this task's own targeted cases below.

Differential tests against Node/Test262 for `for-of`/spread over arrays and
typed arrays including: iterator override mid-loop, length mutation mid-loop,
holes/sparse arrays, proxies, `Symbol.iterator` shadowed on the instance, and
`break`/`return`/`throw` inside the loop body invoking iterator `.return()`.

## Definition of done

- The full iterator protocol remains the exact, spec-authoritative fallback.
- Every guard-invalidation case above is covered by a test that forces fallback
  mid-loop and confirms identical observable behavior to the unspecialized
  path.
- No fast-path selection depends on fixture identity or benchmark vocabulary.

## Performance evidence

Report guard hit rate and per-element iteration cost delta for array/typed-array
iteration workloads plus the existing four-benchmark suite.
