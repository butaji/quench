# 43: Optional Node embedding beyond the Stage A profile

The Stage A Node contract is limited to the `framework-core` fixtures and the
pinned Express, Koa and Fastify scenarios. They pass on the shared VM with
byte-identical local-Node output ([Task 21 evidence](evidence/task21-framework-core-final-2026-10-07.json)).
Broader Node APIs and the full Node inventory are outside this gate.

Keep additional embedding operations pending and non-blocking. During Task 27,
retain only the Node host paths needed by the Stage A profile; remove unused
legacy adapters instead of porting untested APIs. Reopen this task only when a
Stage A fixture or a later selected product workload requires another host
operation.
