# 017: Adopt a compact tagged JsValue representation

- **Theme:** quickjs_perf
- **Executor:** codex
- **Depends on:** 003

## Scope
- crates/quench-runtime/src/dynamic/jsvalue.rs

## Deliverables
- Replace the current unboxed enum JsValue with a compact tagged representation (NaN-boxed 64-bit word, or a documented 16-byte tagged union) following the QuickJS jsvalue.h precedent
- Preserve exact IEEE-754 double semantics, including all NaN payload bit patterns observable via typed arrays
- Update every register/stack/property slot and the GC/tracing code to the new layout in one migration, not a parallel second value type

## Acceptance
- sizeof(JsValue) is reduced and documented against the previous layout
- Full differential and test262 suites pass unchanged
- No behavior depends on which representation form a value happens to take

## Non-goals
- Changing Number/BigInt/typed-array observable semantics
