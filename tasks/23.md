## Outcome

## Dependencies

Discover all pinned `.wast` files including proposals, execute every directive, and require correct parse/validation/runtime/trap classification. Add GC, shared-memory, re-entry, growth, aliasing, and JS/Wasm boundary controls.

## Definition of done

- Every discovered directive passes; there is no Quench skip list.
- Wasm and JavaScript share values/roots through one documented boundary, not duplicate heaps.
- Repeated runs have identical inventory and classification.

## Performance evidence

Report suite time, memory high-water, and representative execution overhead; no speed gate applies.
