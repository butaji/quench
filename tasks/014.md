# 014: Add a bounded megamorphic degrade tier to quickening sites

- **Theme:** deegen_codegen
- **Executor:** codex
- **Depends on:** 007, 013

## Scope
- crates/quench-runtime/src/quickening.rs

## Deliverables
- Replace the permanent Unknown-after-MAX_MISSES behavior with a bounded, generic degrade tier (e.g. a small hashed guard table) that stays cheaper than the complete ordinary path
- Keep the degrade tier's size and admission rule fixed and workload-independent; it must serve any program with the same shape/callee-diversity profile, not a tuned benchmark
- Allow a site to re-specialize if its guard diversity later narrows, without requiring per-fixture tuning knobs

## Acceptance
- A site that legitimately sees more than MAX_MISSES shapes/callees still runs faster than a site with zero caching
- Degrade-tier admission depends only on runtime facts (shape id, callee identity, guard kind), never on fixture name or source
- Cache growth remains bounded and disposable per rule 13/14 in GOAL.md

## Non-goals
- An unbounded polymorphic inline cache or a hidden-class-count-specific special case
