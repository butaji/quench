# 61: Lead no-JIT engines on all eight V8-v7 fixtures

## Outcome

On Apple M4/macOS, on each of the eight V8-v7 fixtures (Crypto, DeltaBlue,
EarleyBoyer, NavierStokes, RayTrace, RegExp, Richards, Splay), Quench has:

- the **highest median Score**, and
- the **lowest median maximum RSS**

among Quench, QuickJS, Bun/JSC with its JIT disabled, and Node/V8 `--jitless`.
Quench stays interpreter-only: no JIT of any kind, no copy-and-patch stencils,
and no executable memory.

## Current gap

Task 26 targets parity with pinned v2 on four fixtures. v2 sits in the
de-JITed engine band ([performance-reference](../docs/v2/performance-reference.md)),
and nothing yet requires Quench to beat the other interpreters, to run the
other four fixtures well, or to minimize memory against them.

## Dependencies

See this task's `depends_on` in [index.json](index.json). This task closes
phase C before the repository contracts are finalized (task 28). It starts from
task 26's v2-parity core and uses task 51's mechanism spikes and the
specializer lane (29–34, 38, 57). Task 62 provides the reference engines in the
runner.

## Scope and implementation sequence

1. Measure all four engines on all eight fixtures with task 62's runner, and
   rank every fixture's Score and RSS gap.
2. Close gaps v2-first. `../v2` and [`docs/v2/`](../docs/v2/) are the reference
   for reaching high scores fast. Port a v2 mechanism wherever one covers the
   gap, then take task 51's beyond-v2 mechanisms.
3. Treat RSS as a first-class target: cell and object footprint (task 50), heap
   growth policy, residual size, string representation, and startup
   allocation. A Score win that loses the RSS gate is not retained, and the
   reverse also holds.
4. Keep every mechanism general, with an exact generic fallback, task 42's
   optimized-versus-generic gate, and the Futamura equation against the
   reference kernel (task 47). No benchmark-shaped behavior, per
   [AGENTS.md](../AGENTS.md).

## Verification

- Use task 26's protocol: at least 11 complete rotating pairs per engine
  comparison, 95% paired intervals, and rejection of drifted, mismatched, or
  invalid runs.
- Every reference engine run records proof that its JIT tiers were off.
- Run the three-suite ratchet and task 24's focused safety controls after every
  retained mechanism.

## Definition of done

- For every fixture and every reference engine, Quench's median Score is
  higher, with the 95% paired interval excluding a tie.
- For every fixture and every reference engine, Quench's median maximum RSS is
  lower, with the 95% paired interval excluding a tie.
- The report includes raw ordered samples, provenance, and engine versions.
- No JIT, stencil, or executable-memory path exists.

## Performance evidence

The matched eight-fixture reports are this task's deliverable. Also report
startup time and RSS, GC counts, and residual bytes per fixture.
