# 50: Restore v2 cell, object, and string footprint

## Outcome

Heap cells, object headers, and strings are no larger than pinned v2's
representation requires, and their sizes are compile-time contracts.

## Current gap

Measured with `-Zprint-type-sizes` on the release profile (2026-09-23,
`target/reviews/core-review-2026-09-23/type-sizes.txt`):

| Type            | Measured | Asserted in `heap/tests.rs` |
| --------------- | -------: | --------------------------: |
| `Cell` / `Slot` |    104 B |                        48 B |
| `Object`        |     72 B |                        16 B |
| `JsString`      |     40 B |                           — |
| `Frame`         |    144 B |                           — |

The assertions never ran because `cargo test -p quench-runtime-next --lib` no
longer compiles (19 errors), so the regression went unnoticed. Its causes:

- `Object` carries `arguments_map: Option<Vec<u16>>`, `arguments_object`,
  `module_namespace`, and `module_bindings: Vec<…>` inline, so every ordinary
  object, array, function, and collection pays for rare exotic state.
- Every cell kind pays the largest variant. String, Symbol, BigInt, and
  Environment cells cost 104 B plus their out-of-line payload.
- `JsString` stores `Rc<[u16]>` plus an eagerly built UTF-8 `host: String`.
  One string is three allocations and about 3 bytes per ASCII unit. Two
  representations of one fact violate the single-authority rule.
- `JsString::push_str` copies the whole string, so repeated concatenation is
  quadratic.

## Dependencies

See this task's `depends_on` in [index.json](index.json). Task 44 moves
mapped-arguments state onto an arguments cell. Coordinate with it rather than
moving the same state twice: this task owns the header size contract, and
task 44 owns where the arguments fact lives.

## Scope and implementation sequence

1. Replace the runtime layout test with compile-time
   `const _: () = assert!(size_of::<…>() == …)` contracts for `Value`, `Instr`, `Object`, `Cell`, and `Slot`,
   matching the existing `Instr` assertion. These are compile-time checks,
   not unit tests, so they respect the current no-unit-test phase.
2. Move arguments and module-namespace state out of the common `Object`
   header into their own exotic cell kinds or a boxed extension. Restore
   v2's 16-byte ordinary header (`proto` plus `ValueVec`).
3. Bound `Cell` by boxing or out-of-lining the large, rare variants
   (ArrayBuffer, TypedArray, DataView, Iterator, FinalizationRegistry) until
   the common kinds fit v2's slot size.
4. Make UTF-16 units (with a Latin-1 one-byte form where every unit fits) the
   single string authority. Derive the host UTF-8 view lazily at host and API
   boundaries only.
5. Give concatenation a builder or rope transition so repeated `+=` is
   amortized linear, with flattening as an explicit transition.

## Verification

Run the full Test262 ratchet. String, object, arguments, and module cohorts
cover the observable behavior. Do not add tests. The size contracts must
compile under `cargo check -p quench-runtime-next`.

## Definition of done

- The size contracts are compile-time and hold on the release profile.
- The ordinary object header and common cell kinds match pinned v2's sizes,
  or the task records a measured justification for each extra byte.
- Strings have one unit authority. The host view is derived and never
  retained in the cell.
