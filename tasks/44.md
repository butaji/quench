# 44: Fold remaining identity-keyed state into cells

## Outcome

Restore v2's representation rule: per-object semantic facts live on the
object's heap cell or its immutable shape, and `Vm` owns only realm-wide and
per-site state. No `FxHashMap<Value, _>` or `FxHashMap<(Value, _), _>` is a
semantic authority.

## Current gap

Pinned v2's `Vm` holds shapes, transitions, atoms, constants, and flat per-site
cache arrays. It holds no identity-keyed semantic state. The next core has
added nine identity-keyed tables:

| Table                               | Fact                            | Home in the v2 design                               |
| ----------------------------------- | ------------------------------- | --------------------------------------------------- |
| `argument_maps`, `argument_objects` | mapped `arguments` exotic state | an arguments cell kind                              |
| `generators`                        | generator record                | generator cell                                      |
| Promise state (task 17)             | promise record                  | promise cell, owned by task 17                      |
| `function_values`                   | per-function derived values     | function cell or realm table indexed by function ID |

Property descriptors and Symbol properties are deliberately excluded here:
task 08 owns them together in the immutable ordered shape authority. Each
remaining identity-keyed fact duplicates object identity, must be swept or
traced by hand at collection, and adds a hash lookup to paths v2 keeps on
cells/shapes. Task 36 already removed the same pattern for integrity flags.

The 2026-09-23 core review found two more forms of the same duplication:

- **Native functions keyed by their own identity.** `PromiseRuntime` holds
  eight `FxHashMap<Value, _>` tables. Apart from `records`, they (`jobs`,
  `thenable_jobs`, `finally_jobs`, `finally_continuation_jobs`, `aggregates`,
  `aggregate_jobs`, `async_resume_jobs`) mostly map a
  runtime-created native function back to its captured data. The Proxy revoke
  target and similar per-closure facts follow the same pattern. One concept
  covers them all: a native function cell that carries its typed data.
- **Internal slots stored as hidden atoms.** About 30 engine-internal facts
  are properties or bindings named `\0rqj:…`, for example `string-value`,
  `number-value`, `boolean-value`, `symbol-value`, `bigint-value`, `home`, and
  `proxy-revoke-target`. These are ECMAScript internal slots such as
  `[[StringData]]` and `[[HomeObject]]`. They belong on the cell. Task 49 owns
  the call and local path (`arrow`, `self-binding`, `new-target`,
  `lexical-this`, `super-called`); this task owns the per-object ones.

## Dependencies

See this task's `depends_on` in [index.json](index.json). Property and Symbol
state belongs to task 08 and must not be implemented again here. This task
introduces the native-function-with-data cell; task 17 moves the Promise
tables onto it and owns the promise record itself.

## Scope and implementation sequence

1. Keep descriptor attributes and string/Symbol properties in the single
   shape representation established by task 08; no parallel tables remain.
2. Move mapped-arguments state onto the arguments object cell and generator
   state onto the generator cell. Promise state is owned by task 17's promise
   cell rather than migrated a second time here.
3. Move `function_values` onto the function cell or a flat realm table indexed
   by stable function ID, choosing the representation from its lifetime and
   tracing requirements.
4. Add a native function cell form that carries typed per-closure data,
   traced with the cell and defined once alongside the task 46 registry row
   for its native. Move existing runtime-created closures whose data now lives
   in identity-keyed tables onto it, except the Promise family, which task 17
   moves.
5. Move per-object internal slots stored as `\0rqj:` atoms onto the owning
   cell, such as primitive wrapper data and home object. Reflection then has
   nothing to filter out.
6. Remove associated per-table GC sweeps and audit remaining `Vm` fields for
   identity-keyed semantic authority. Do not add a structural unit test.

## Verification

Run the full Test262 ratchet and use its existing cases for descriptors,
Symbol/string ordering, mapped-arguments aliasing, and generator/promise
behavior. Do not add tests or change the Test262 harness. Review GC tracing and
collection paths directly for ownership completeness.

## Definition of done

- No per-object internal slot is represented as an atom name.
- Every remaining identity-keyed semantic fact has one home on its cell,
  shape, or stable realm table; no fact is duplicated in `Vm` maps.
- Field-cache hits are justified by shape identity alone.
- `collect_slow` has no per-table sweeps for these facts.
