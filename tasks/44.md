# 44: Fold remaining identity-keyed state into cells

## Plan scope

Deferred outside the active two-stage plan. This retained proposal is not a
prerequisite for Stage A or Stage B. Select a concrete part only for a proven
correctness need or a measured performance gap; otherwise leave it unstarted.

## Outcome

When evidence selects this mechanism, give the selected per-object fact one
cell/shape authority and derive its execution views. Avoid duplicated identity
or state without treating every indexed table as inherently wrong.

## Current gap

Mapped-arguments metadata already belongs to object extras, and generator
state belongs to iterator cells. `function_values` is a weak cache keyed by
program/function identity, not a strong per-object semantic authority.

Promise records and callback data still use nine identity-keyed tables:
`records`, `jobs`, `thenable_jobs`, `finally_handler_callbacks`,
`finally_continuation_callbacks`, `aggregates`, `aggregate_jobs`,
`reaction_capabilities` and `async_resume_jobs`. Task 07 derives their child
edges from reachable owners and prunes dead-owner metadata. The superseded
`finally_jobs`, `finally_continuation_jobs` and `finally_reactions` pipeline
is removed. Table membership is not a GC root.

Descriptor fallback metadata covers keys without shape slots, including array
length/elements; task 08 owns that domain. It is not a duplicate authority for
shape-slot attributes. Some internal slots still use hidden atom properties;
a census must identify a concrete cost before selecting a storage change.

## Dependencies

See `depends_on` in [index.json](index.json). Task 17 owns Promise behavior and
producer lifetime correctness; it does not wait for this proposal. Task 08 owns
properties/descriptors. Do not implement either authority a second time here.

## Scope and verification

1. Census the selected fact's owners, readers, writers, lifetime and measured
   lookup/allocation/GC cost. Cite the relevant pinned v2 evidence.
2. Put that fact on its owning cell or immutable shape only if the measured
   need justifies it. Use typed native-function data for selected captures;
   retain a single authority and derive all access/tracing views.
3. Remove the superseded table, atom storage, wrappers and sweep path once
   consumers have moved. Preserve task 07's owner-tracing and queue semantics.
4. Run affected Test262 stages plus compare-runs, relevant implemented Node
   and Wasm scopes, and internal forced-GC controls. Preserve suite inputs.

## Definition of done

- The selected fact has one authoritative representation and explicit lifetime.
- Reflection, ordering, errors and GC behavior remain correct.
- Superseded storage and consumers are removed; retained caches are derived.
- Paired production measurements justify any performance claim. Report cell/VM
  bytes, GC work and affected Score/RSS; remove a rejected experiment.

No broad cell rewrite or removal of every identity-keyed map is a stage gate.
