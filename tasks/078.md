# 078: Generate Node dispatch from the registry

`registry.rs` is intended to be the canonical API declaration, but
`dispatch.rs` repeats hundreds of capability constants and handwritten lookup
matches. Consolidate the fact once and derive dispatch views from it.

## Plan

- Add an explicit dispatch kind/handler reference to registry rows (or a small
  parallel declarative table for signature-variant handlers).
- Generate capability aliases and call/construct lookup tables with a macro.
- Preserve dynamic, ranged, and exceptional dispatch paths as visible code.
- Remove duplicated literals and fix duplicate/unreachable match arms.

## Acceptance

All existing capability IDs, ordering, constructors, errors, and host effects
match the pre-change oracle. Add compile-time coverage for every registry row
and run the Node dispatch test matrix.
