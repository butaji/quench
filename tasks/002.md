# 002: Remove workload-specific kernels from production execution

- **Theme:** benchmark_integrity
- **Executor:** codex
- **Depends on:** 001

## Scope
- crates/quench-runtime/src/functions*
- quench-bench

## Deliverables
- Delete benchmark fixture helpers, kernels, and their recognizers from quench-runtime
- Delete production dispatch that recognizes benchmark source, names, scores, checksums, or shapes
- Keep reusable generic primitives only when they preserve ordinary JavaScript semantics

## Acceptance
- Default quench-runtime compiles no workload-specific kernel modules or dispatch arms
- No benchmark-only module or benchmark-shaped recognizer is compiled into quench-runtime
- The neutral corpus still executes through ordinary semantics and preserves observable results

## Non-goals
- Adding a replacement benchmark fast path
