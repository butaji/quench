# 079: Generate mechanical Node handler adapters

## Outcome

Replace repeated uniform host wrappers with typed generated adapters.

## Current gap

`dispatch_handlers.rs` contains mechanical argument/receiver forwarding alongside genuinely exceptional behavior.

## Dependencies

See this task's `depends_on` in [index.json](index.json); status and ordering live there.

## Scope and implementation sequence

1. Classify adapters by typed signature and receiver/argument semantics.

2. Generate uniform adapters from registry facts, migrating one module family at a time.

3. Delete superseded wrappers; retain nonuniform behavior as explicit named handlers.

## Verification

`cargo test -p quench-node`; `cargo run -p quench-node-test --bin run-compat`; Node differential cases for missing/extra arguments, receiver errors, constructors and side effects.

Apply the shared [completion checks](README.md), including named baseline failures
and independent semantic controls. Record commands and artifact identity.

## Definition of done

- All uniform migrated wrappers derive from one declaration.
- Receiver adaptation, callable identity, error order and host effects remain correct; exceptional paths stay visible.

## Performance evidence

Structural milestone; no speed claim without matched evidence.
