# 011: domain: error propagation edge cases

- **Theme:** surface_gaps
- **Executor:** codex
- **Depends on:** 006

## Context

Filename-prefix frequency: `domain-no` (10 hits), `domain` (2), plus
`domexception` (2, likely unrelated — DOMException, not the `domain`
module; verify before lumping together). `domain.rs` exists. The `domain`
module is deprecated in Node but still tested; it wraps async_hooks-style
resource tracking to route errors to a domain's `'error'` handler, which is
why this depends on 006 landing first (shared resource-lifecycle
machinery).

- Do not touch `DOMException` (part of the web-platform error types,
  unrelated module) unless a specific fixture proves otherwise
