# 76: Inline statically known callees in the residual

## Plan scope

Stage B candidate after task 86 verifies Stage A. Select this work only for a
measured V8-v7 Score or RSS gap; finishing it is not a stage-completion gate.
Use affected-stage checks plus compare-runs during changes. The current
dependencies in [index.json](index.json) supersede older prerequisite claims.

## Outcome

Small callees that are statically known are inlined into the caller's
residual, so the call frame, argument binding, and return dispatch disappear.
Every observable effect of a call is kept: stack traces, the recursion budget,
and sloppy `caller` and `arguments.callee` behavior.

## Current gap

Every call creates an activation, even for a known, non-recursive,
`pure`-graded callee whose body is a few instructions. The interpreter has no
inlining. Self and HotSpot showed that inlining exposes most of the later
static facts to the caller, and Self-91 also showed that inlining everywhere
blows up code size.

## Scope and implementation sequence

1. Census hot call chains before cloning. Pinned v2 tasks 86/207 are
   negative evidence for cold polyvariant clones: task 86 was score-neutral
   and increased Crypto/Richards RSS. Select only hot-chain-bounded variants,
   charging residual and metadata growth to the paired gate.
   A call site is eligible when its callee is statically known (task 71), is
   not recursive, is strict or does not reference `arguments` or `caller`, is
   not a generator or async function, and has a residual below a named size
   bound. The bound documents its code-size cost and falls back to an
   ordinary call when it is exceeded.
2. Inline by copying the callee's residual with its registers renamed into the
   caller's frame, and bind parameters directly.
3. Keep observable call structure as data: each inlined region records a
   virtual frame in task 63's position table, so stack traces, `Error.stack`,
   and task 65's interruption report the callee frame. The recursion budget
   counts virtual frames.
4. Declare a resume map for every inlined region. An exception or
   interruption inside the region resumes as if the callee frame existed
   (forced-failure resume check, as in task 33).
5. Rerun the binding-time analysis on the inlined result, so task 57's, 73's and
   74's facts see through the call.

## Verification

Test262 cases for `Error.stack`-dependent behavior covered by the frozen
Node set, `new.target`, `this` binding, and exceptions from inlined bodies.
Stack-overflow tests with inlined frames. Generic-mode controls disable inlining
and compare with the existing path.

## Definition of done

- Inlined and non-inlined execution are observably identical, including stack
  traces and stack-overflow boundaries.
- Eligibility and the size bound are declared data with a documented cost.

## Performance evidence

Report inlined sites, residual growth, and the paired V8-v7 Score/RSS delta.
Record a negative result if the gate is lost.
