# 375 — Guarded equality opcode stencils

Status: complete

Extend Task 373's maximal closed-block fold with four general rustc/LLVM-cooked
primitive leaves: strict equality, strict inequality, loose equality, and loose
inequality. The handlers compare immediate numbers, booleans, nullish values, and
identity-bearing heap values directly. String-content comparison, coercive string
conversion, and an owned reference-counted destination take the canonical slow edge
before the bytecode has performed an observable effect.

The four handlers are generated by one `define_dyn_equality!` macro and share one quoted
`loose_equal_without_string_conversion` semantic reducer. Named raw-value tags and
truthiness constants define the representation; the implementation introduces no
literal tag, frame-offset, or branch-encoding magic numbers. Each leaf remains a
`Stencil<Connector, Connector>` and therefore composes with every other primitive in the
same free-monoid block expression.

This is bytecode-driven and always available. It uses no source identity, benchmark
identity, execution counter, or hotness threshold.

## Reach and correctness

Task 373's residual frontier predicted 662,575 newly closable entries from strict
equality alone, 366,592 from loose equality alone, and 1,029,167 from their combination.
The implemented candidate reduced generic helper entries and expanded direct cover in
the measured suites, including:

- Richards: 3,878,895 -> 3,732,339 helper entries and 72/244 -> 77/298 direct
  blocks/opcodes;
- Crypto: 1,431,476 -> 1,344,891 and 427/1,480 -> 453/1,636;
- Earley-Boyer: 6,729,926 -> 6,608,296 and 825/2,357 -> 921/2,752.

All eight smoke suites and all 139 release tests pass. Focused tests cover numeric and
nullish strict equality, null/undefined loose equality, boolean-to-number loose equality,
strict inequality, and the string/number slow edge. The differential cooker audit passes
at both O2 and O3 over 151 catalog symbols, 47 placeholder-sensitive stencils, and all 89
typed holes in `reports/task375-stencil-cooker-audit/`.
