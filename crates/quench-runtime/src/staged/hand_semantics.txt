#
# Completion criteria (P4/P5/P6):
# P4: no site outside the three categories below. The categories are binding-time facts, not
#     debt: the hot loop's direct compares avoid a class-table load per instruction; a
#     value-dependent use needs the opcode *value* (a const generic, handler-table key or
#     `NAMES` lookup); a per-op body does operation-specific work, not family dispatch.
# P5: every host/VM callout crossing a lane body (allocation, element get/set helpers, global
#     read, field-store helper, interrupt/collection safepoint) is an `Operation` with an
#     `EmitFrame` implementation and a `Concrete` decline test in `staged::tests`.
# P6: a body gets per-pc precise windowed masks whenever its tables fit `MAX_MASK_BYTES`
#     (4 MiB); beyond that it gets a sound all-live map (tested: no per-pc entry, so every
#     consumer treats every register as live), never a missing map.
#
